# 张雪峰事件打标数据：聚类与梗词标注（CLUSTERS.md）

> 数据：用户提供 `抖音微博小红书-全量已打标.xlsx`（52,736 条，2026-01-31 → 2026-05-31，抖音 16,602 / 小红书 33,328 / 微博 2,806）。
> 本目录产出供给主题体系与梗词标注，是 LLMABM 供给池与 agent 类型的数据基础。

## 1. 数据与处理

1. **人工打标**（用户提供）：`数据有效性`（有效 32,530 / 无效 20,186 / 存疑 20）× `内容类别`（有效=事件悼念讨论 / 其他讨论 / 教育观点讨论 / 梗文化讨论；无效=借势营销 16,156 / 爬取噪音 4,030）。
2. **去重**：content 归一化 MD5 → 30,507 唯一文本（平均重复 3.88×，重复次数保留为 `dup` 字段 = 再生产强度）。
3. **主题聚类**：jieba 分词 → TF-IDF(1-2gram, min_df=5, max_df=0.3) → LSA(100) → MiniBatchKMeans(k=12, seed=42)。k 由 silhouette 扫描（6-16，k=12 峰值 0.083）+ 可解释性共同确定。
4. **后处理**：C3+C6 合并为「巧乐兹雪碧梗」（同一广告梗被聚成两簇，佐证梗文本多样性极低）；C10（小红书话题模板）/C11（评论抓取残留）标记噪音。
5. **梗词标注**：`meme_matcher.py` 实现《张雪峰梗词判定规则(完整版)》（联动人名出现即玩梗 → 死亡事实陈述排除 → 强梗词库两层匹配，高召回口径）。

## 3. 关键实证事实（直接进入模拟参数）

1. **死亡冲击波**：悼念颂扬 03-23 → 0，03-24 → 1,236 条/日，三日衰减 1236→1073→764，两周内回落至 ~100/日。指数衰减脉冲，可直接参数化供给侧事件响应。
2. **供给高度分散**：26,821 独立作者 / 32,530 条，作者发帖量 Gini=0.156，Top1% 作者仅占 7%。**供给侧无垄断者**——与文献「曝光集中于少数赢家」（L021/L022）形成核心张力：供给分散 + 曝光集中 ⇒ 排序贡献可在模拟中被隔离（Q1 归因设计依据）。
3. **梗是抖音特有供给**：巧乐兹雪碧梗 98% 在抖音；悼念/语录/干货主要在小红书。平台差异化供给必须建模。
4. **梗供给持续存在**：玩梗供给占比死亡日 4.7% → 第 3 日起稳定在 5-6% 直到 4 月上旬——「第一天悼念、第二天玩梗」的时间线梗在供给占比上体现温和但持续；梗簇峰值 05-25（死亡两个月后仍在产生新梗帖）。
5. **悼念帖内含回旋镖**：悼念颂扬主题 18.4% 被判玩梗——哀悼与玩梗同框，不是两个互斥池。
6. **有效供给中 23.9% 是玩梗**；无效侧另有借势营销 16,156 条（营销号蹭热点，占全量 31%）。
7. **去语境化素材现成**：语录类（C0/人生语录、C9 部分与 C5 部分）多为无上下文「张雪峰说：…」体——生前话语的切片化再生产是数据中最大的去语境化供给（对应机制链环节 5）。

## 5. 局限

- 爬取口径：interaction 字段仅小红书/微博 reach，无逐帖点赞/转发 → 供给侧用文本重复度（dup）与发帖量作再生产强度代理，真实互动分布不可得。
- 打标「有效/无效」是研究侧判断；平台算法不做此区分，模拟供给池应包含借势营销（作为噪音供给，见 DESIGN 文档）。
- 梗判定为高召回口径（用户已确认接受误伤），is_meme 用于治理干预模拟（限流降权）时同样高召回。
- k=12 的 silhouette 偏低（0.083，短文本常态），主题边界经人工核验可解释；C5 泛议论杂谈是兜底大簇，配置生成时其采样权重应下调。
