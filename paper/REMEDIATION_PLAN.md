### B. 核心轨迹对标注器稳健，但**主比较结论不稳健**

同一批 Agent 供给轨迹固定不变，只替换效标标注器重算受限多变量 DTW
（`hypothesis_4/experiment_1/results/labeler_sensitivity/REPORT.md`；与冻结效标逐格校验 0 不一致）：

| 标注器 | 三臂排序（优→劣） | interest vs random 配对 t 检验（n=3） |
|---|---|---|
| DeepSeek | **interest** > random > chronological | 差 −1.71 pp，t=−2.46，**p=0.133** |
| doubao-seed | **random** > interest > chronological | 差 +3.48 pp，t=20.20，**p=0.002** |
| GLM | **random** > interest > chronological | 差 +0.51 pp，t=0.38，**p=0.737** |
| DeepSeek-V4.1 | **random** > interest > chronological | 差 +2.54 pp，t=1.91，**p=0.197** |

→ 论文"兴趣制度拟合最优"这一中心比较结论，**在三个独立重打标轮下方向均反转**；即使按原标注器也不显著。
  必须撤销或以"标注器依赖"如实报告。

**稳健的部分**（四个标注器一致，可保留为主贡献）：悼念峰值周 W13、事件前玩梗基线 ≈0.5%、
W19 回升、**W20 起爆**、W22 峰值，即"教育—悼念—玩梗"三阶段与玩梗延迟爆发。
**不稳健的部分**：W22 玩梗份额区间 **41.5%–63.0%**（正文引用的 63.0% 是上限），
悼念峰值 34.8%–43.6%。

### C. 构念循环：**盲法判类已解耦，核心结论得到支持**（此节曾在 2026-09-25 被误判，已更正）

- 环境代码自述：`pool_type` **恒等于 Agent 固定类型（by construction）**，`assigned_type` 是环境
  用**与生成提示同一套四词表**对正文的复核（`custom/envs/curation_dynamics_space.py:1218`）。
- 对 9 个正式 run 的 1,904 条生成帖，用**独立模型（GLM，与生成模型 `deepseek-v4-flash` 不同族）
  只看正文做盲法判类**（不含臂/身份/周次/词表；与真实帖打标同一套 prompt；
  成功判定 1,887 条，17 条被内容审核拒绝）。结果（`results/blind_classification/REPORT.md`）：

| 比较 | 一致率 | Cohen's κ |
|---|---|---|
| 身份标签 vs 盲法文本判类 | **86.5%** | **0.822** |
| 身份标签 vs 环境四词表复核 | 42.2% | 0.233 |
| 环境四词表复核 vs 盲法文本判类 | 52.8% | 0.314 |

- **结论一（解耦成功）**：身份标签与独立文本判类的 κ = 0.822（almost perfect）；
  玩梗身份 97%、悼念 100%、营销 100%、教育 85% 被盲判为同一类。
  用**文本类别**重算的周级玩梗轨迹与身份口径几乎重合：

  | 臂 | W19 | W20 | W21 | W22 |
  |---|---|---|---|---|
  | random 身份／文本 | 0.0%／0.0% | 4.2%／4.2% | 28.9%／28.9% | 44.3%／37.6% |
  | chronological 身份／文本 | 0.0%／0.0% | 66.2%／66.2% | 85.6%／84.1% | 83.0%／83.0% |
  | interest 身份／文本 | 4.8%／4.8% | 70.9%／66.6% | 82.6%／79.3% | 82.8%／81.2% |

  即"玩梗供给上升"是生成文本的真实属性，不是身份标签的产物；W2 的这一半可以据实回答。
- **结论二（坏仪器）**：环境自带的四词表复核几乎无区分度（把 57.7% 的生成帖判为悼念、
  仅 1.7% 判为玩梗），其 `mismatch_rate` 诊断（57.8%）**没有测量学意义**，论文中不得引用为
  "类型错配"证据，应改用本节的盲法审计。
- **结论三（保留的弱点）**："其他讨论"身份是残差类，仅 20% 被盲判为同类（66% 判为悼念），
  四类核心（教育/悼念/玩梗/营销）为 85%–100%。凡涉及"其他"口径的结论需注明该不确定性。
- **仍存在的限制**：生成提示强制各 Agent 使用类型词表，故"类型一致性"部分是设计要求而非独立发现；
  论文能主张的是**轨迹**（何时起爆、幅度多大）而非"文本自发跨类"。三臂排序在文本口径下仍不稳健
  （对 DeepSeek 效标 interest 最优，对 doubao/GLM/DeepSeek-V4.1 效标 random 最优），与标注器敏感性结论一致。

### D. 事实性错误：注入量被放大 10 倍

正文 `:81` 写"模型**每周**从真实数据中抽取约 250 条帖文作为外部输入"。实测每个 run 的注入
**总量为 250 条**，周分布为 W12–W22 = 17/35/30/24/22/19/18/18/20/23/24
（`_derived/data/*/weekly_supply.csv`，9 个 run 完全一致）。即约 **23 条/周**，而非 250 条/周。
这同时意味着：模拟场域约 88% 的内容由 Agent 自身产出，外生现实输入很薄——这一点必须在正文中如实说明。

### E. 目标泄漏（r3 W1，与上并列阻断）

W19–W22 的真实帖（含玩梗类别构成）在每个 Agent 当周决策前进入候选池，而 W19–W22 又被称作
"后段检查窗口"（正文 `:81`、`:141`）。因此"三臂都复现了 W20 起爆"与外生输入完全相容，
不能作为生成性解释力的证据。附带问题（r3 W1 第二问）：100 个 Agent 的类型比例由 **W12–W22**
发帖口径导出，属**事后定义**，不能据此声称"事件前既有的玩梗群体规模"。

### F. 池化现实曲线受平台构成影响：量级与"主导性"结论不成立

分平台重建周级轨迹（`hypothesis_4/experiment_1/results/platform_heterogeneity/`）后：

| 平台 | n | 玩梗起爆周 | W22 玩梗（DeepSeek） |
|---|---|---|---|
| 抖音 gsdata | 16,600 | W19 | 82.4% |
| 小红书 sinamidu | 33,317 | **W21** | **19.3%** |
| 微博 weibo | 2,799 | W22 | 40.8%（悼念峰值在 W21 而非 W13） |

平台间差异**远大于**标注轮间差异。把每周平台构成固定为全窗口总体构成（直接标准化）后：

| 标注器 | 起爆周 | W22 玩梗（原始池化 → 标准化） | W22 最大类（标准化后） |
|---|---|---|---|
| DeepSeek | W20（不变） | 63.0% → **39.9%** | 玩梗（39.9% vs 营销 30.1%） |
| GLM | W20（不变） | 51.6% → **32.7%** | 玩梗（32.7% vs 营销 31.5%，仅差 1.2pp） |
| DeepSeek-V4.1 | W20（不变） | 45.2% → **28.7%** | **营销（30.8%）**，玩梗第二 |
| doubao-seed | W20（不变） | 41.5% → **25.6%** | **营销（30.0%）**，玩梗降至第三 |

结论：
- **稳健**：W19 回升 / W20 起爆 / W22 达峰这一**相位结构**，对标注轮与平台构成标准化都稳健；
- **不稳健**：量级（25.6%–63.0%）；"玩梗已成为主导性公共表征"在四个标注轮中有**两轮**
  标准化后由营销反超（DeepSeek-V4.1、doubao-seed），另两轮玩梗仅以 1.2–9.8pp 领先。
- 早期的数据挖掘审查其实已记录过平台分化（`DATA_MINING_REVIEW.md` 保留项 1：抖音 W19 30%→W22 82%，
  小红书同期仅 →19%），但该信息未进入仿真设计与正文；仿真把三平台混合建模，与这一事实不符。
