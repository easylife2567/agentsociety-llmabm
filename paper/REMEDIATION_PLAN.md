## 1. 已确认的硬伤与证据

### A. 编码口径：正文声称"人工编码"，实际为纯 LLM 打标（诚信风险，最高优先级）

- 正文四处声称人工：摘要（`manuscript.accepted.md:3`）、方法（`:77` "经人工标注"、"三列人工编码"）、
  数据性质（`:145`）、表 4（`:211`）、结论（`:272`、`:276`）。`ARCHIVE_MANIFEST.md`、`DATA_MINING_REVIEW.md`
  与 `data_mining_report_*.md` 同样写作"人工打标"。
- 实际链路：`抖音微博小红书-全量已打标.xlsx` 的六类标签由 **DeepSeek** 产出
  （见 `compare_labels.py` 中"DeepSeek 原标"口径），随后用 doubao-seed、GLM 各做一轮独立重打标。
  **不存在人工编码环节，不存在编码手册、编码员与一致性记录。**
- 三方一致性（`标签一致性对比报告_20260925.md`，n=52,736）：

| 比较 | 类别一致率 | Cohen's κ | 有效性一致率 | κ |
|---|---|---|---|---|
| DeepSeek vs doubao-seed | 53.9% | 0.4303 | 76.4% | 0.4945 |
| DeepSeek vs GLM | 59.5% | 0.4972 | 78.7% | 0.5546 |
| doubao-seed vs GLM | 72.6% | 0.6495 | 86.1% | 0.7053 |
| 三方同时一致 | 47.0% | — | 70.6% | — |

- 分歧高度结构化，集中在**借势营销 ↔ 教育观点讨论**边界；玩梗类总量在三个标注器间差异很大
  （13.6% / 8.5% / 9.7%）。

### B. 核心轨迹对标注器稳健，但**主比较结论不稳健**

同一批 Agent 供给轨迹固定不变，只替换效标标注器重算受限多变量 DTW
（`hypothesis_4/experiment_1/results/labeler_sensitivity/REPORT.md`；与冻结效标逐格校验 0 不一致）：

| 标注器 | 三臂排序（优→劣） | interest vs random 配对 t 检验（n=3） |
|---|---|---|
| DeepSeek | **interest** > random > chronological | 差 −1.71 pp，t=−2.46，**p=0.133** |
| doubao-seed | **random** > interest > chronological | 差 +3.48 pp，t=20.20，**p=0.002** |
| GLM | **random** > interest > chronological | 差 +2.61 pp，t=2.95，**p=0.098** |

→ 论文"兴趣制度拟合最优"这一中心比较结论，**在两个标注器下方向反转**；即使按原标注器也不显著。
  必须撤销或以"标注器依赖"如实报告。

**稳健的部分**（三个标注器一致，可保留为主贡献）：悼念峰值周 W13、事件前玩梗基线 ≈0.5%、
W19 回升、**W20 起爆**、W22 峰值，即"教育—悼念—玩梗"三阶段与玩梗延迟爆发。
**不稳健的部分**：W22 玩梗份额区间 **41.5%–63.0%**（正文引用的 63.0% 是上限），
悼念峰值 34.8%–43.6%。

### C. 构念循环：模拟中的"玩梗"是身份而非文本

- 环境代码自述：`pool_type` **恒等于 Agent 固定类型（by construction）**，`assigned_type` 是环境
  用**与生成提示同一套四词表**对正文的复核（`custom/envs/curation_dynamics_space.py:1218`）。
- 对 9 个正式 run 的 1,904 条生成帖实测（`results/blind_classification/extraction_summary.json`）：

| 口径 | 玩梗 | 悼念 | 教育 | 营销 | 其他 | 噪音 |
|---|---|---|---|---|---|---|
| `pool_type`（身份，论文现用） | 291 | 318 | 363 | 693 | 239 | 0 |
| `assigned_type`（环境四词表复核） | **38** | **1097** | 14 | 753 | 2 | 0 |

  身份与四词表复核的不一致率为 **57.8%**。四词表复核几乎无区分度（玩梗 2%、教育 0.7%），
  说明论文图 3b/图 4 的"玩梗供给上升"是"身份为玩梗的 Agent 发言更多"，不是生成文本的语义转移。
- 已冻结 1,904 条正文并启动**盲法判类**（生成模型 `deepseek-v4-flash`；判类用 GLM 与 doubao-seed，
  只看正文，不含臂/身份/周次/词表），用于出身份—文本错配矩阵并用文本类别重算轨迹。

### D. 事实性错误：注入量被放大 10 倍

正文 `:81` 写"模型**每周**从真实数据中抽取约 250 条帖文作为外部输入"。实测每个 run 的注入
**总量为 250 条**，周分布为 W12–W22 = 17/35/30/24/22/19/18/18/20/23/24
（`_derived/data/*/weekly_supply.csv`，9 个 run 完全一致）。即约 **23 条/周**，而非 250 条/周。
这同时意味着：模拟场域约 88% 的内容由 Agent 自身产出，外生现实输入很薄——这一点必须在正文中如实说明。

### E. 目标泄漏（r3 W1，与上并列阻断）

W19–W22 的真实帖（含玩梗类别构成）在每个 Agent 当周决策前进入候选池，而 W19–W22 又被称作
"后段检查窗口"（正文 `:81`、`:141`）。因此"三臂都复现了 W20 起爆"与外生输入完全相容，
不能作为生成性解释力的证据。附带问题（r3 W1 第二问）：100 个 Agent 的类型比例由 **W12–W22**
发帖口径导出，属**事后定义**，不能据此声称"事件前既有的玩梗群体规模"。
