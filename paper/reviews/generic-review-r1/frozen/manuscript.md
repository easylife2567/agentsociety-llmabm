<span class="insertion" data-author="续昼"
data-date="2026-09-15T17:58:48Z">**（一）数字哀悼与逝后表征：从“被记住多少”到“被记住什么”**</span><span class="paragraph-insertion"

<span class="insertion" data-author="续昼"
data-date="2026-09-15T17:58:48Z">数字媒介拓展了哀悼的参与主体、表达形式与持续时间。周葆华、钟媛通过分析李文亮微博下134万余条评论，发现临时性的集体悼念可以转化为持续运作的“延展性情感空间”，兼具情感表达与集体记忆书写功能<sup>\[</sup>[^1]<sup>\]</sup>。高嘉潞进一步指出，陌生人借助信息补偿、固定仪式和记忆书写等实践维持与逝者的联结，并在互动中重新协商逝者身份<sup>\[</sup>[^2]<sup>\]</sup>。这些研究表明，数字哀悼同时包含情感表达、关系维系和形象建构。</span><span class="paragraph-insertion"

<span class="insertion" data-author="续昼"

**（二）研究方法**

本研究采用基于大语言模型的多智能体仿真方法，将公众人物逝世后的社交媒体舆论场建模为由平台信息环境与<span class="deletion"
data-author="张人杰"
data-date="2026-09-15T13:16:46Z">异质性</span>用户共同构成的动态系统。<span class="deletion"
data-author="张人杰"
data-date="2026-09-15T13:16:54Z">选择该方法的原因在于，</span>本文试图解释的<span class="insertion"
data-author="张人杰"
data-date="2026-09-15T13:17:07Z">社交媒体</span>表征漂移并非单一主体的行为结果，而是平台持续配置内容可见性、用户依据所见环境作出表达选择、新产生的内容再次进入平台分发的循环过程。传统的结果态数据可以呈现不同内容类型的数量与份额变化，却较难直接观察这一循环中的微观行为过程。

<span class="insertion" data-author="张人杰"
data-date="2026-09-15T13:17:49Z">仿真</span><span class="deletion"
data-author="张人杰"
data-date="2026-09-15T13:17:44Z">模型不以复刻现实平台的全部功能为目标，而是</span>围绕“平台如何组织可见信息、用户如何决定是否表达、个体表达如何聚合为宏观内容构成”三个环节进行机制化抽象。平台端负责真实内容注入、内容池维护和个体信息流生成；智能体端负责读取信息流、判断是否发声并生成相应内容。通过改变平台的信息流生成制度，并保持事件输入、用户群体和表达规则相对一致，本文考察不同策展环境下用户表达与宏观表征的演化差异。

因此，本研究属于基于真实事件的机制建模与结构反事实比较。模型能够检验一组明确的微观规则是否足以形成与现实相似的宏观轨迹，并比较不同策展制度下轨迹的变化，但不将模型内差异直接等同于现实平台算法的净因果效应。

**2. 平台—用户交互过程**

<span class="deletion" data-author="张人杰"
data-date="2026-09-15T16:34:20Z">每一</span><span class="insertion"
data-author="张人杰"
data-date="2026-09-15T16:34:23Z">每一轮</span>仿真周期依次经历现实帖子注入、个体信息流生成、用户感知与表达决策、内容回流四个环节。<span class="paragraph-deletion"
data-author="张人杰" data-date="2026-09-15T18:20:39Z"></span>

环境按现实时间将外部帖子注入公共内容池，平台依<span class="deletion"
data-author="张人杰"
data-date="2026-09-15T16:34:47Z">实验条件</span><span class="insertion"
data-author="张人杰"
data-date="2026-09-15T16:34:50Z">策展制度</span>为每个智能体生成10条帖文的信息流；智能体据此更新同类内容可见度与累积曝光，并由<span class="deletion"
data-author="张人杰"
data-date="2026-09-15T16:35:09Z">表达效用</span><span class="insertion"
data-author="张人杰"
data-date="2026-09-15T16:35:11Z">表达决策模型</span>决定发声或沉默。发声者生成的内容回到公共内容池，成为后续周期的可分发对象。

这一过程可以概括为：

``` math
P_{t}\overset{\Gamma}{\longrightarrow}F_{it}\overset{U_{it}}{\longrightarrow}X_{it}\overset{词表约束生成}{\longrightarrow}P_{t + 1}
```

其中，$`P_{t}`$表示时期$`t`$的公共内容池，$`\Gamma`$表示平台的<span class="deletion"
data-author="张人杰"
data-date="2026-09-15T16:35:27Z">信息流生成</span><span class="insertion"
data-author="张人杰"
data-date="2026-09-15T16:35:29Z">策展</span>制度，$`F_{it}`$表示智能体$`i`$当期所见的信息流，$`U_{it}`$表示其表达效用，$`X_{it}`$表示发声或沉默的行为结果。

**（1）平台策展制度Γ<span class="deletion" data-author="张人杰"
data-date="2026-09-15T16:35:32Z">（信息流生成制度）</span>**

这里的$`\Gamma`$表示平台将时期t的公共内容池$`P_{t}`$组织为智能体i当期信息流$`F_{it}`$的规则，而非大语言模型的文本生成。平台先从当期可用内容中确定候选池，再按实验条件为每个智能体配置10条帖文：全历史随机制度从截至当期的全部帖文中均匀无放回抽样；时序制度读取行动时点前最新发布的帖文；兴趣制度依据智能体固定类型与帖文正文倾向分的匹配程度进行比例抽样，不引入帖子热度。三种制度共享相同的智能体、现实输入和U模型，各设置3个随机种子，同一随机种子跨制度匹配注入样本。改变$`\Gamma`$即改变用户发言前“看见什么”，并通过同类内容的可见份额与累积曝光进入$`U_{it}`$的计算。

**（2）用户表达决策模型U**

智能体的表达决策由锚定式效用模型描述：

``` math
U_{it} = B_{i} + R_{it}(D_{it} - B_{i})
```

当$`U_{it} \geq a_{i}`$时，智能体$`i`$在时期$`t`$选择发声；否则保持沉默。其中，$`a_{i}`$为个体表达门槛，$`B_{i}`$为常态表达效用，$`D_{it}`$为当期意见气候效用，$`R_{it}`$为注意力余量。$`{}_{}`$个体表达门槛以0.95为共同基数，该基数由同构信息流下的数值扫描确定；初始化时为每个智能体乘以0.8—1.2的随机扰动并在全程固定，以保留个体异质性。各类型采用同一基数，是因为实证数据中各类型人均发帖强度均接近1，缺乏设置类型差异门槛的依据。

常态表达效用$`B_{i}`$表示智能体在没有强事件刺激时的基础表达倾向<span class="insertion"
data-author="张人杰"
data-date="2026-09-15T16:43:56Z">。</span><span class="deletion"
data-author="张人杰"
data-date="2026-09-15T16:43:54Z">，</span>由W05—W12各类型常态供给映射到上述门槛分布的相应分位点后固定：玩梗0.7755、悼念0.7678、营销0.8252、教育0.7412、其他0.7686。该变量使事件刺激消退后的表达水平回归各类型常态，而不是随累积曝光机械下降至零。

意见气候效用$`D_{it}`$根据智能体所见信息流中同类内容的相对可见度计算：

``` math
D_{it} = 1 + \alpha_{D}s_{i}\tanh\left( k\frac{share_{it}^{own} - base_{i}}{base_{i}} \right)
```

其中，$`share_{it}^{own}`$表示智能体信息流中与其所属类型一致的内容份额，$`base_{i}`$表示该类型在智能体总体中的人口比例，$`s_{i}`$表示个体对意见气候的敏感程度，$`\alpha_{D}`$为全局缩放参数。当同类内容的可见份额高于其人口基准时，智能体的表达意愿得到增强；当同类内容处于相对不可见状态时，表达意愿受到抑制。<span class="paragraph-insertion"
data-author="张人杰" data-date="2026-09-15T16:41:25Z"></span>

注意力余量$`R_{it}`$根据智能体累积接触同类内容的数量计算：

``` math
R_{it} = \exp\left( - \lambda_{i}\frac{cum_{it}^{own}}{scale} \right)
```

其中，$`cum_{it}^{own}`$表示智能体截至当期累积接触的同类内容数量，$`\lambda_{i}`$表示其注意力衰减速度。随着重复曝光增加，事件刺激对表达的影响逐步减弱。

这一组合方式具有两个边界。当$`R_{it} = 1`$时，$`U_{it} = D_{it}`$，智能体的表达主要由当期意见气候决定；当$`R_{it}`$逐步趋近于零时，$`U_{it}`$回归常态效用$`B_{i}`$。因此，该模型同时描述了事件发生后的表达激活、持续曝光中的注意力衰减，以及事件热度消退后的常态回归。

**（三）观测指标与模型评价**

**4. 作用边界与结果约束**

以上结果支持两个层次的结论。生成性层面，三种制度均捕捉到W20以后玩梗表征快速上升的基本时序，其中Interest制度相对现实五类构成轨迹的平均DTW距离最低。机制比较层面，Interest制度在二次增长阶段产生了最高的玩梗型Agent发言率和最大的玩梗内容回流量，但其W22总体玩梗曝光低于Chronological制度，说明表征演化不能由单一曝光指标解释。核心证据因此指向平台可见性配置与用户表达决策的共同作用，而非平台算法或用户偏好任何一方的单向决定。

结论仍受三项边界约束：其一，每种制度只有3个正式seed，包络同时反映随机过程与注入样本差异，制度比较宜作描述性判断；其二，注入池在W17和W18缺少玩梗内容，使仿真对二波之前的连续积累刻画不足；其三，图4a以Agent-only供给同现实内容构成作结构性比较，二者生成机制不同，数值接近应理解为生成性验证而非同量纲预测。B、D、R消融结果用于识别模型内部机制的方向性作用。

**五、讨论**

**1. 机制层面的解释**

三臂比较表明，不同策展制度不仅改变内容的总体可见度，也会改变可见内容与既有用户类型之间的匹配关系，并由此形成不同的话语演化动力。Interest制度在受限多变量DTW评价中取得最低平均距离，同时在W20—W22产生了最强的玩梗型用户激活和内容回流。其机制优势并不表现为对玩梗内容总体曝光量的简单最大化，而在于将个体信息流与Agent的既有类型特征相联系，使差异化曝光进入表达效用U，并通过用户发帖回流持续重组后续内容环境。宏观表征漂移因而应被理解为平台策展与用户表达循环作用的结果。

**2. 与既有文献的对话**

本研究的发现可与三条文献脉络相互印证。在数字哀悼方面，真实数据呈现的spike+decay形态与West等对公众人物逝后注意力模式的刻画一致，而仿真进一步揭示了悼念退潮之后玩梗接续的机制条件——这正是既有研究多停留于"被记住多少"而较少触及的"被记住什么"的转向。在迷因传播方面，本研究回应了"玩梗为何在悼念退潮后才大规模爆发"的时序之问：沉默螺旋与注意力衰减共同构成了悼念让位、玩梗起爆的时序前提，单纯的内容可复制性不足以解释这一延迟。在算法策展方面，本研究支持"算法可放大与重组既有表达"的判断，但通过收窄主张表明，这种放大并非均匀作用于全局话语，而是在玩梗通道最为显著——这与曝光结构改变不等同于全局认知转变的实证结论相呼应。

**3. 平台治理含义**

三臂对比的差异化结果提示，分发规则是塑造逝后话语形态的可干预杠杆。若平台意在缓解逝者被迷因化消费的趋势，调整推荐逻辑（如降低高情绪可复制内容的曝光增益）可能比单纯的内容删除更接近机制层面的治理。但本研究仅在机制建构层面展示这种可能性，并未对具体治理方案作因果评估，相关推论应止于"方向性提示"。

**六、结论与局限**

**1. 主要贡献**

本研究以基于大语言模型的多智能体仿真，建构并考察了“平台策展—用户表达”循环作用下公众人物逝后社交媒体表征的转移，主要贡献如下。其一，机制建构：以Γ描述平台对可见性的组织，以U描述用户发声或沉默，并通过词表约束的内容生成完成反馈循环。其二，现象解释：正式仿真表明，现实输入、平台策展与用户表达可以共同涌现“教育—悼念—玩梗”的表征转移；B、D、R数值推演消融进一步识别了常态锚点、意见气候和注意力余量的方向性作用。其三，制度比较：Interest制度在受限多变量DTW评价中取得最低平均距离，并在二次增长阶段形成最强的玩梗型用户激活与内容回流，表明信息流生成制度会通过改变用户表达和内容回流，塑造表征漂移的幅度与路径。

**2. 局限**

本研究存在如下局限，逐条列出以划定结论的适用边界。其一，各正式实验臂仅3次重复，相关比较宜作描述性判断。其二，seed同时更换了注入样本，标准差合并了随机过程与注入池重采样差异，并非纯Monte
Carlo误差。其三，注入池在W17和W18缺少玩梗内容，使模型难以生成现实中低水平、连续积累的玩梗轨迹。其四，仿真绝对量与真实数据存在量纲差，绝对量只用于比较归一化后的形态，不直接比较规模。其五，研究为单案例设计，结论向其他逝者或事件外推需谨慎。其六，大语言模型驱动的智能体具有黑箱属性，本研究只在输入—输出层面保证可控与可追溯。其七，100个智能体、11周的规模应理解为机制建模，而非平台级舆情的代表性再现。其八，B、D、R消融基于100个配对seed的数值推演，其结论限于模型规则内部的方向性识别。其九，本研究旨在进行生成性验证与制度比较，不将模型内差异直接表述为现实平台算法的净因果效应。

**3. 未来工作**

后续研究可在如下方向延伸：扩大种子数与案例覆盖以增强统计推断力；引入不同网络拓扑与平台结构考察结构敏感度；对推荐逻辑中的热度信号作系统性敏感性分析；以更长的真实数据窗口支撑参数标定与验证。

综上，本研究为公众人物逝后数字表征的转移提供了一个可操作、可证伪的机制解释框架，并指出不同分发规则对话语演化形态的差异化塑造，为理解算法时代的公共话语演化提供了机制层面的参照。
