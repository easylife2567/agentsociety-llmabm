# 人工抽检编码手册（spot check codebook）

*用途：为 `抖音微博小红书-全量已打标.xlsx` 的类别标签提供人工复编码可靠性证据。*
*建立于 2026-09-25，配合 `paper/REMEDIATION_PLAN.md` 动作 1。*

---

## 1. 背景与目标

现有六类标签由大语言模型生成，**没有人工编码环节**。四轮跨模型一致性中，与原标的两两
κ = 0.430–0.511（独立重打标轮之间为 0.668–0.767），
低于内容分析常用的可接受阈值（κ ≥ 0.67，严格口径 ≥ 0.80）。因此需要人工复编码回答：

> 周级玩梗轨迹——尤其是 W19 回升与 W20 起爆——是否对编码误差稳健？

**本抽检不是重新编码全量数据**，而是在分层样本上估计编码可靠性，并把该误差传播到关键结论上。

---

## 2. 编码单元与样本

- 编码单元：单条帖文。
- 样本：400 条，按「平台 × 周」分层（W05–W22），由
  `draw_spot_check_sample.py` 生成。
- 盲化：编码表中**不含**周次、不含平台（若正文未自带）、不含原模型标签、不含判定依据；
  条目顺序随机打乱。编码者不应查证事件时间线，也不应回看已编码条目。

## 3. 类别定义（六选一，不允许自创）

| 类别 | 定义 |
|---|---|
| **借势营销** | 以商品、服务、账号引流、带货、二维码、价格、链接、限时优惠等为目的的推广内容；或借某热点人物/事件为特定产品/服务背书引流 |
| **事件悼念讨论** | 对逝者、事故、灾害、公共事件的缅怀、哀悼、点烛、RIP、默哀类内容；或围绕此类事件的严肃讨论 |
| **教育观点讨论** | 知识科普、观点输出、教育理念讨论、人生感悟、有信息增量的分析类内容（非营销） |
| **梗文化讨论** | meme、谐音梗、段子、玩梗、跟风玩梗、无实义的网络流行语、搞笑吐槽类内容 |
| **其他讨论** | 以上四类都不符合，但仍是正常有意义的帖子（如日常分享、生活记录、提问求助、情感抒发） |
| **爬取噪音** | 乱码、纯表情、@好友无意义内容、无意义短文本、广告刷屏残留、空内容、格式损坏等无实质信息的条目 |

## 4. 判定顺序（必须按序执行）

1. **是否噪音**：内容残缺/乱码/纯@人/纯表情/无意义短文本 → 爬取噪音
2. **是否营销**：出现带货、引流、招生、课程售卖、价格、联系方式、二维码、"进群"等推广目的 → 借势营销
3. **是否悼念**：对逝者/事故/灾害的缅怀、哀悼、追思 → 事件悼念讨论
4. **是否玩梗**：meme、段子、谐音梗、跟风玩梗、围绕死亡方式的戏谑符号（如"巧乐兹/雪碧/你跑不过我"） → 梗文化讨论
5. **是否教育观点**：知识输出、观点分析、教育理念、人生感悟 → 教育观点讨论
6. **以上都不符合** → 其他讨论

## 5. 边界规则（针对已知的高分歧区）

本抽检的主要价值在于「借势营销 ↔ 教育观点讨论」这一边界（三方分歧集中于此），请严格执行：

- **B1 有推广目的就是营销，不因内容本身有信息量而改判教育。**
  例："张雪峰推荐的中外合办院校名单 + 学费 + 报名方式" → 借势营销。
- **B2 纯知识/观点输出、无任何转化目的 → 教育观点讨论。**
  例："考研复试如何准备英语口语"（无课程链接、无进群、无报价） → 教育观点讨论。
- **B3 借热点人物为**自营产品**背书 → 营销**，即使通篇在谈该人物的观点。
- **B4 仅引用某人的话作为人生感悟的引子、正文是个人反思 → 教育观点讨论。**
- **B5 玩梗判定优先于教育**：若正文核心笑点/符号是死亡方式相关梗，即使夹带观点 → 梗文化讨论。
- **B6 广告刷屏残留**（重复文本、营销模板残片但无完整推广语义） → 爬取噪音，不是营销。
- **B7 无法判断时**填 `存疑`，并在备注列写明原因；不要强行归入某一类。

## 6. 有效性判定（二选一）

- **有效**：包含可用于后续研究分析的实质内容（有完整语义、有明确主题）
- **无效**：无实质内容、纯噪音、纯营销引流无研究价值、或内容过于残缺无法分析

## 7. 操作流程

1. 运行抽样：`python draw_spot_check_sample.py --n 400 --coders 2`
   → 产出 `sample/coderA.csv`、`sample/coderB.csv`（两份内容相同、顺序各自独立打乱）
   与 `sample/key.csv`（**编码者不得查看**）。
2. 两名编码者**各自独立**填写 `category`、`valid`、`note` 三列；不得互相讨论。
3. 收回后运行：
   ```bash
   python compute_agreement.py --a sample/coderA.csv --b sample/coderB.csv --key sample/key.csv
   ```
   → 产出编码者间 κ、与模型标签的 κ、逐类混淆矩阵，以及**人工标签下的周级玩梗轨迹与起爆周**。
4. 分歧裁定：由第三人（或两名编码者协商）对分歧条目作最终裁定，记录裁定依据；
   报告"编码者间一致性"与"裁定后与模型标签一致性"两组数字。

## 8. 报告要求

补充材料中至少报告：

- 抽样框与分层方式、样本量、编码者人数与是否盲于周次/假设
- 类别级与有效性级：一致率 + Cohen's κ（或 Krippendorff's α），逐类混淆矩阵
- 玩梗类在不同编码口径（模型三轮 + 人工两轮 + 裁定）下的周级份额区间
- 关键结论的敏感性：**W20 起爆周是否在人工编码下仍然成立**
- 分歧集中于哪些边界，以及裁定规则

## 9. 反例（常见误判）

| 帖文特征 | 错误判法 | 正确判法 | 依据 |
|---|---|---|---|
| 讲述学习方法，末尾"进群领取资料" | 教育观点讨论 | 借势营销 | B1 |
| 引用张雪峰名言 + 个人人生感悟 | 借势营销 | 教育观点讨论 | B4 |
| 通篇谈某产品，开头引逝者名言 | 事件悼念讨论 | 借势营销 | B3 |
| "巧乐兹配雪碧"类死亡方式玩笑含观点 | 教育观点讨论 | 梗文化讨论 | B5 |
| 重复的营销模板残片、无完整语义 | 借势营销 | 爬取噪音 | B6 |
