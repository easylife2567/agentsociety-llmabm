## 排版

| 项目 | 本稿设置 |
|---|---|
| 正文中文／英文 | 宋体／Times New Roman，均小四12 pt；Word中明确设置东亚与西文字体 |
| 纸张、版心 | A4纵向、单栏、四边2.54 cm；采用写作run的页边距要求 |
| 正文段落 | 两端对齐、固定20 pt行距、首行缩进24 pt（两字）、段前后0 |
| 标题 | 题名主标题18 pt、副标题16 pt分行居中；一级14 pt加粗，二级12 pt加粗，保留原中文编号层级 |
| 图表 | 五图按原比例嵌入，宽不超过15.92 cm；图题居下、表题居上，图注与表内文字10.5 pt；表1采用三线表 |
| 公式 | 原生Word公式，可编辑；保留U组合式和正文内变量下标 |
| 引用、书目 | 作者—年份制，22项去重书目，12 pt、24 pt悬挂缩进；英文书名、期刊名及卷号按书目分段斜体 |
| 页码 | 底部居中动态页码，含首页 |

版式参考主工作区旧PDF的A4单栏、约20 pt行距、两字缩进与图下标题；旧PDF左右约3.175 cm，本稿按run要求采用2.54 cm。正文和字号服从作者本次要求。参考PDF实测见[格式记录](qa/reference_format.json)。

交付DOCX指定的中文字体为“宋体”。本机未安装Windows版SimSun，因此PDF预览在临时渲染副本中使用系统宋体-简（Songti SC），交付Word的字体设置不改。Times New Roman为本机实际字体；原图中的字体保留已制图版本。
