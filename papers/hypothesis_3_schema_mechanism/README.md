## 精读等级

| 等级 | 数量 | 含义 |
|---|---:|---|
| 全文级 | 5 | 已依据本地保存的正文及结构化抽取核对方法、结果和边界 |
| 摘要级 | 1 | 依据作者摘要与题录分析，不报告摘要未提供的统计细节 |
| 理论重建级 | 5 | 未取得合法开放全文；依据可核验题录、摘要信息及后续经典综述重建其理论位置，不冒充全文精读 |

“理论重建级”不是低价值，而是证据访问层级不同。它适合说明概念谱系和机制方向，不适合为 ABM 提供未经核验的精确系数。

## 使用原则

1. 文献决定变量关系和可检验边界，不自动给出本项目的数值参数。
2. “重复使命题更像真的”不能直接改写为“重复使人物印象更单一”；二者之间是 H3 要检验的桥接环节。
3. 熟悉度只是图式丰富度的代理，必须与情感认同、粉丝身份、既往接触量和关系距离分开。
4. H3 应保留双向可能：既有图式可能抵抗碎片，也可能通过确认偏差放大图式一致片段。
