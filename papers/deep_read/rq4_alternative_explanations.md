## 2. 逐篇精读要点

**L020｜不要把责任归给算法：多个推荐系统及其对内容多样性影响的实证评估（A）**
- 核心主张：在同一真实新闻库（荷兰大报 de Volkskrant，21,973 篇）与 500 位真实用户数据上并列模拟 7 种推荐逻辑（编辑策展、总体热度、协同过滤/语义过滤、有无用户历史的变体、随机基线），发现被测试的所有推荐逻辑都产生与人工编辑相当、相对多样的推荐集；基于用户历史的协同过滤甚至可显著提高推荐集内的话题多样性。「算法必然造成收窄」被强反证，「单一化」必须设为待测结果而非前提。
- 证据类型与等级：数据科学模拟实验（Level III，卡片评级 A）；识别策略为最相似设计 + 随机基线对照，非真实平台 RCT。
- 竞争解释维度：算法放大 与 内容供给。控制内容供给（同一新闻库）后算法未必然降低多样性，提示曝光集中更可能来自内容供给侧或曝光规则组合而非排序算法本身。
- 区分研究设计的启示：在同一内容供给上做**因子消融**；多样性按话题、来源/类别、语气、标签多维操作化而非单一总指标；设置随机基线作为「无算法」对照的替代。
- 可校准参数：LLMABM 推荐逻辑参数化——popularity 权重、item-to-item vs user-history 协同过滤、语义过滤、随机基线；多样性报告按话题距离（如 LDA 主题距离）、来源、语气多维输出。
- 限制：荷兰报纸文章推荐模拟 ≠ 抖音短视频推荐的实时曝光-反馈循环；未测观点多样性；模拟而非平台真实数据。

**L025｜对新闻推荐系统选择性曝光条件效应的建模：来自两个在线实验的证据（B，题录级）**
- 核心主张（题录/摘要级，未取得卡片）：以两个在线实验建模新闻推荐系统对选择性曝光的**条件效应**，主张推荐器对选择性曝光的作用取决于内容与用户条件，「推荐器增加/减少选择性曝光」的总体概括不成立。具体实验设计与效应量需回查原文。
- 证据类型与等级：在线实验（题录级；未核对原文细节）。
- 竞争解释维度：算法放大 × 用户选择 的交互——算法效果是条件性的，用户属性决定算法发挥放大还是缓冲作用。
- 区分研究设计的启示：采用**条件效应（调节）设计**：将推荐器类型与用户特征（政治立场、熟悉度）交叉，检验「单一化印象」是否只在特定子群出现；对低熟悉用户子样本单独做条件分析。
- 可校准参数：LLMABM 中让算法参数与用户属性交互——低熟悉用户的信息来源多样性权重、曝光集中度阈值按熟悉度分层。
- 限制：题录级，无法核对实验条件、样本与效应量；工作区无正文。

**L026｜理解在线信息消费中人与算法纠缠的挑战（A）**
- 核心主张：在线信息消费是用户偏好、交互行为、社会网络与排序系统长期共同演化的结果，「有算法/无算法」不存在干净对照；人与算法沿「隐性到显性需求」连续体纠缠，短期交互会通过社会网络结构的长期变化反向塑造算法环境；即使是严格时间倒序流（recency-only feed）本身也是一种算法，且结构性偏向高频发布者。
- 证据类型与等级：概念与证据评论（Level VII，卡片评级 B）；无新实验，不构成因果证据。
- 竞争解释维度：覆盖全部五个维度——尤其指出**内容供给与粉丝组织（高频发布者）**即使在没有排序算法时也会造成曝光集中，破除「非算法流=中性」假设。
- 区分研究设计的启示：对照组不能命名为「无算法」，必须明确指定曝光规则（recency-only、随机、热度）；呼吁平台数据透明与外部研究保护。
- 可校准参数：LLMABM 必须允许用户行为修改下一轮曝光（双向反馈）；允许长期关注/社群结构演化；对照条件 = 明确指定的曝光规则而非「无算法」。
- 限制：叙述性评论，无新实证与因果识别。

**L027｜数字媒体中的社会驱动因素与算法机制（A）**
- 核心主张：对福祉、错误信息与极化相关证据的简要回顾表明，算法在这些现象中的作用「远非直截了当」，现有证据更多指向**算法主要是强化既有社会驱动力**而非独立第一因；应把平台结果视为算法机制与社会驱动因素共同作用的产物。
- 证据类型与等级：评论（Level VII，卡片评级 A）；非系统综述、无新因果识别。
- 竞争解释维度：算法放大 vs 内容供给/用户选择/社会文化——算法是**条件性放大器**；若 ABM 把供给、选择、社群组织全部写进算法参数，将无法区分解释。
- 区分研究设计的启示：最稳妥假设是「推荐作为条件性放大器」；设计必须分离供给、排序、用户选择、社群组织与平台治理五个环节并分别报告边际贡献。
- 可校准参数：把算法参数作为调节器而非唯一驱动——先校准内容供给端与用户偏好端参数，再以因子消融单独检验算法开关/参数的边际贡献。
- 限制：非系统综述，无新实证。

**C30｜信息茧房效应下用户群体极化形成机理研究（B，CNKI 摘要级）**
- 核心主张（严格基于摘要）：基于「刺激-机体-反应」框架与信息生态理论构建信息茧房效应下用户群体极化作用机理模型，问卷调查 + 结构方程模型实证：信息同质化、选择性接触、群际情绪和社会比较频率在用户群体极化行为意愿形成中发挥重要作用，用户态度极化也是影响因素。未取得全文，具体路径系数与效应量不可引用。
- 证据类型与等级：问卷调查 + SEM（摘要级）；相关/路径证据，非实验因果。
- 竞争解释维度：内容供给（信息同质化）、用户选择（选择性接触）、粉丝组织（群际情绪、社会比较）——同质化曝光导致收敛的路径是多因的，算法曝光只是其中一条。
- 区分研究设计的启示：把信息同质化、选择性接触、群际情绪、社会比较作为中介或条件变量纳入机制模型；SEM 路径思路可映射为 ABM 中可独立开关的机制模块。
- 可校准参数：内容库同质化程度、用户选择性接触强度（偏好权重）、群际情绪传染强度、社会比较频率、态度极化阈值——均可独立参数化并消融。
- 限制：摘要级；自报问卷的构念效度与共同方法偏差未知；结论为相关而非因果。

**L035｜Trick and Please：关于 TikTok 算法的用户假设的混合方法研究（B，题录级）**
- 核心主张（题录级）：混合方法研究 TikTok 用户对算法的**假设/民间理论**——用户感知算法不透明，认为点赞、完播、话题标签等互动行为会被算法计入，并据此调整行为（「算法迷信/博弈」）。这是关于用户信念的研究，不是对算法实际行为的审计。
- 证据类型与等级：混合方法（问卷+访谈，题录级）；用户自我报告信念，不能证实算法真实行为。
- 竞争解释维度：用户选择——用户对算法的信念驱动其点击/划走行为，是「用户选择」解释的操作基础；也为粉丝组织「投喂算法」提供行为微观基础。
- 区分研究设计的启示：测量用户的算法信念（folk theory）可区分「用户主动选择」与「算法被动推送」在曝光中的相对贡献；在 LLMABM 中给用户显式算法信念参数并对比有无信念两种条件。
- 可校准参数：用户对算法的信念与操作策略（认为点赞/完播/不感兴趣影响曝光）→ 转化为点击、跳过、关注的选择概率。
- 限制：题录级；信念 ≠ 算法真实机制；非抖音中国大陆版本样本。

**L036｜算法民间理论与身份：TikTok 用户如何共同生产身份知识并进行算法抵抗（B，题录级）**
- 核心主张（题录级）：访谈研究发现 TikTok 用户把身份（种族、性别、性向等）与算法对待方式联系起来，共同生产「身份如何影响算法」的民间理论，并采取算法抵抗行为（如调整内容、清理历史、切换账号）。
- 证据类型与等级：质性访谈（题录级）；样本有限，不外推因果。
- 竞争解释维度：用户选择 + 身份相关的供给感知——受众对曝光的解释具有能动性，印象形成不纯是被动接受推荐；用户先验身份与社群知识调节解释收敛。
- 区分研究设计的启示：在受众解释收敛模型中引入用户的先验信念分布与抵抗行为；问卷/访谈采集低熟悉用户的先验以初始化 agent。
- 可校准参数：用户先验信念分布、算法抵抗概率（主动划走/举报/清理历史/切换账号）。
- 限制：题录级；质性研究不可作因果推断。

**L041｜Facebook 上意识形态多元新闻与观点的曝光（B，题录级）**
- 核心主张（题录级，通行学术知识，不引用具体数字）：利用 Facebook 大规模去识别用户数据（自报意识形态的美国用户）比较「新闻流排序曝光」与「用户完整朋友流（反事实基线）」：跨意识形态内容的曝光削减大部分来自**用户自身选择**（好友结构、取消关注、点击偏好），排序算法造成的削减相对较小；好友网络的供给结构本身也决定曝光。此结论常被解读为「用户选择与供给 > 算法排序」。
- 证据类型与等级：大规模观测数据 + 反事实基线分解（题录级）；著名的观察性分解研究，非平台 RCT。
- 竞争解释维度：算法放大 vs 用户选择 vs 内容供给（好友网络）——三者中后两者贡献更大；排序仍有独立的（较小的）作用。
- 区分研究设计的启示：**反事实基线法**可直接迁移：对同一内容供给同时运行「算法排序流 / 纯时序流 / 随机流」三种条件，分解排序算法的边际贡献。
- 可校准参数：LLMABM 中设三种反事实曝光条件（算法排序 / 按发布时间的关注流 / 随机基线），比较低熟悉 agent 印象收敛速度与标签集中度；好友/关注网络结构参数。
- 限制：题录级；2015 年 Facebook 新闻流 ≠ 2026 年抖音；自报意识形态样本；无随机对照。

## 3. 综合：竞争解释地图

**现有证据强度排序（由强到弱）**
1. 模拟实验（L020，Level III）：在控制供给条件下，算法未必然降低多样性——直接反证「算法必然放大」。
2. 大规模观测+反事实分解（L041，题录级但通行结论成熟）：用户选择与供给贡献大于排序。
3. 在线实验条件效应（L025，题录级）：算法效果是条件性的。
4. 问卷调查+SEM（C30，CNKI 摘要级）：同质化→极化路径多因，非算法单因。
5. 概念/证据评论（L026、L027，Level VII）：算法多为既有社会驱动力的强化者；不存在「无算法」对照。
6. 质性/混合方法（L035、L036，题录级）：用户信念与能动性证据。

**对「算法放大」核心假设的挑战**
- 削弱面：L020 直接表明在相同供给下推荐逻辑不必然窄化；L027 主张算法主要强化既有社会驱动力；L041（题录级）显示用户选择与供给结构对曝光削减的贡献大于排序；L026 指出纯时序流同样结构性偏向高频发布者（曝光集中可完全来自非算法机制）。
- 支持/保留面：L041 同时承认排序仍有独立（较小）效应；L026 确认人-算法双向反馈，算法可放大即时交互并经由网络结构产生长期效应；L027 承认算法作为条件性放大器的作用；C30 支持「同质化曝光→态度极化」的链节，但提示途径多元（选择性接触、群际情绪、社会比较）。
- 净结论：现有证据支持把「算法放大」从**充分原因**降级为**条件性放大器/必要环节之一**；单一化印象更可能是供给集中 × 排序强化 × 用户选择收敛三者的合谋。

**为张雪峰案例设计区分的建议（可观察变量）**
- 反事实曝光条件（区分算法放大 vs 其余）：同一内容供给下跑「算法排序流 / 按发布时间纯时序流 / 随机基线流」三组，比较低熟悉 agent 的印象标签集中度（如 Shannon 熵/HHI）；若算法组显著高于时序组 → 支持算法放大；若三组无差异 → 指向供给或选择。
- 内容供给侧（区分内容供给）：测量「少数片段」在供给库中的占比 vs 其在实际曝光中的占比——控制片段供给占比后，算法边际贡献若消失则单一化源于供给集中。
- 用户选择侧（区分用户选择）：分解「曝光→点击」比与「点击→印象」贡献；比较曝光集中度与点击集中度；引入无点击的纯曝光对照组。
- 粉丝组织（区分粉丝组织）：关注列表中粉丝组织账号占比、社群再分发强度（转发/合拍网络）作为调节变量；比较高/低粉丝组织暴露用户的印象差异。
- 新闻周期（区分新闻周期）：按死亡后时间窗切分（0-24h / 24-72h / 一周后），热度驱动阶段 vs 个性化驱动阶段的印象收敛速率与标签结构差异。
- 结果变量清单：首次接触片段属性（首因印象）、印象标签集多样性、片段来源集中度、跨用户曝光同质度。
