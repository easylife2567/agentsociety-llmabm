# 停止更新公众人物的算法推荐与公众认知

## 研究问题

> 在张雪峰去世后，抖音平台的推荐机制如何参与关于他的碎片化叙事传播，并如何影响不了解他的用户对其形成单一化、标签化的印象？

待验证的候选过程是：

`第三方截取/去语境化 → 少数片段反复获得曝光 → 解释变化 → 低熟悉度用户形成标签化首因印象`

这是候选机制，不是已证明的因果链。

## 阶段结论

现有证据最稳健的解读是：**推荐算法更可能是死后人物叙事的条件性放大器、曝光组织者和反馈循环协调者，而不是单一化标签的唯一生产者。**

文献分别支持以下子环节：去语境化/迷因化可能改变解读；用户行为信号和推荐策略可改变曝光结构；重复曝光可提高命题的感知真实性并参与分享决策；低熟悉度人物判断会受有限线索影响。但没有文献端到端验证“张雪峰去世—抖音推荐—新用户标签化印象”。

结论必须同时保留以下竞争解释：创作者供给、用户选择、粉丝组织、死亡新闻/纪念周期与平台治理。

## 未完成与不可越过的边界

- 中文本土付费数据库尚未经用户机构授权完成系统检索，当前正文库存在OA与英文文献偏差。
- 张雪峰去世目前仅归档了二手公开报道线索，尚未归档原始讣告。
- “雪毙”、“你跑不过我你信吗”的原始视频、完整语境、曝光规模、推荐路径与用户实际印象均未核验。
- “偏离原意”后续应优先与张雪峰生前较大范围的自主表达语料比较，其次与片段所在的原始完整视频比较；当两种标准结论不一致时必须分开报告。

## 研究纪律

- 不把“平台推荐算法发挥了作用”预先当作已证实事实。
- 将排序、候选内容供给、用户选择、粉丝组织、新闻/纪念周期与平台治理分开考察。
- 保留不支持初始判断或与之矛盾的研究。
- 只对已取得和核验的正文作结论级综合。
