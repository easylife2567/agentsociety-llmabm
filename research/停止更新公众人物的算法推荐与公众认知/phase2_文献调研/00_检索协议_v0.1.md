# 文献检索协议（v0.1）

## 目标

为已确认的总研究问题建立可复现、可扩展的文献证据库。当前为范围性、问题导向的 literature review，不宣称达到 PRISMA 系统综述的穷尽性。

## 数据库与用途

| 来源 | 用途 | 当前可用性 |
|---|---|---|
| OpenAlex | 跨学科广泛发现、引用信息、开放获取线索 | 可程序化检索 |
| Semantic Scholar | 题名/DOI存在性核验、去重 | 已执行：66/67匹配 |
| Crossref | DOI与正式出版元数据核验 | 可程序化核验 |
| Google Scholar | 引文追踪、书籍章节与跨库补漏 | 浏览器定向补充 |
| CNKI/万方 | 中文传播学、新闻学与短视频研究 | 访问条件待确认 |
| 出版社/DOI落地页 | 原始元数据与全文线索 | 对入选文献定向核验 |

实际执行的题录发现/核验来源为OpenAlex、Crossref、Semantic Scholar、DOI落地页、出版社开放页与开放机构仓储。Google Scholar、CNKI和万方尚未完成可复现的系统检索，不计入“已检索数据库”。

未实际执行的数据库不得写入最终“已检索数据库”清单。

## 时间、语言与文献类型

- 检索时段：2005-01-01至2026-08-17。
- 例外：更早的奠基性首因效应、重复曝光、框架与社会记忆理论。
- 语言：英语、简体中文、繁体中文。
- 类型：同行评审论文、学术专著/章节、正式会议论文、学位论文、可信研究报告；新闻仅用于案例事实，不作为理论证据。

## 纳入标准

1. 直接讨论死亡后的数字身份、在线悼念、公众人物记忆或平台化再现；或
2. 提供去语境化、片段再生产、推荐放大/可见性集中机制的证据；或
3. 提供重复曝光、标签化、框架化与陌生人物印象形成的证据；或
4. 提供区分算法、用户选择和内容供给的研究设计；或
5. 为后续 LLMABM 提供可观测变量、行为规则或校准证据。

## 排除标准

- 仅讨论线下哀悼且不能解释媒介/认知机制。
- 仅优化推荐准确率，不讨论曝光结构、内容多样性或受众影响。
- 仅为新闻、营销稿、博客或无法核验的二手摘要。
- 研究对象仍在持续自主生产内容，且论文不提供可迁移机制。
- 题名与摘要无关；或重复出版版本中元数据较不完整者。

## 两阶段筛选

1. Title/Abstract：按五类纳入路径标注 `核心 / 支持 / 外围 / 排除`。
2. Full text：提取方法、样本、平台、机制、结果、限制、竞争解释和对本RQ的贡献。

## 来源核验

- 每条候选文献优先核验 DOI、题名、作者、年份和出版源。
- 使用 Semantic Scholar、OpenAlex、Crossref 三索引交叉核验；API失败时记录降级，不把“未查到”自动视为虚构。
- 有 DOI 的文献须解析到正式页面并核对题名。
- 未取得原文时，不声称已针对原文核验研究发现。

## 目标数量

- lit-review 最终目标：至少25条入选学术来源。
- 同行评审来源比例目标：不少于60%。
- 先广泛发现，再根据证据缺口补检；不为达到数量而降低相关性。

## 分布偏斜检查

对最终入选集检查年份、地域、方法和出版源。任一已知维度单一值达到70%时，记录 `DISTRIBUTIONAL_SKEW_ADVISORY`，但不自动排除文献。
