# 数据图

打开[图表总览.html](图表总览.html)可离线浏览全部18张PNG；点击图片可打开原图放大查看。按用户要求不保留SVG。

单平台与合计的周图下方附全部18周的数字表：占比图显示五类比例及每周分母，数量图显示各类精确帖数、五类合计及全部记录，悼念/玩梗图分别列出数量和占比。跨平台图也附逐周对照表；总览及核心四类图附W13、W19、W22的比例与样本量。曲线上标出关键数值，日图标事件日与峰值；百分比保留1位小数，精确比例仍在CSV和Excel中。

- `00_总览_各平台及合计`：四面板占比总览。
- `抖音/小红书/微博/三平台合计`各3张：类别占比、类别数量、悼念与玩梗占比和数量对照。
- `跨平台`2张：关键类别占比比较、样本量与玩梗数量比较。
- `稳健性_01_固定平台构成对照`：保持平台占比不变后与实际加总比较。
- `补充`2张：排除营销的核心四类构成、合计逐日讨论演变。

[图表索引.csv](图表索引.csv)列出每张图的图注与对应作图表。全部图采用基准标签。
