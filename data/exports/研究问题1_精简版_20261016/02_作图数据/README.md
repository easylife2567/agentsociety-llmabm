# 作图数据

本级9份CSV均只含基准标签：

| 文件 | 内容 |
|---|---|
| `基准_全部平台_逐周.csv` | 3平台和合计，共72行 |
| `基准_抖音/小红书/微博/三平台合计_逐周.csv` | 4份单独周表，各18行 |
| `基准_分平台及合计_逐日.csv` | 各平台和合计的逐日计数与占比 |
| `各平台及合计_时间特征汇总.csv` | 分母、峰值周、W22玩梗占比及描述阈值 |
| `固定平台构成_逐周.csv` | 基准的实际加总与固定平台构成比例，18行 |
| `固定平台构成_权重.csv` | 三平台全窗五类帖数及固定权重，3行 |

数量单位是条；比例为0—1。五类和四类分母由列名标明。数据与汇总Excel内容一致。
