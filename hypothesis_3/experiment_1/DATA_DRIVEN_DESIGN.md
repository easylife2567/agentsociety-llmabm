报告指出「玩梗内部有重度/轻度分化」「悼念不是铁板一块」「教育内部分化明显」，故每族保留风味维度（按簇内占比分配）：

| 族 | 风味（占比） |
|---|---|
| 玩梗娱乐 | 重度玩梗（73%，簇0）· 轻度玩梗（27%，簇6） |
| 悼念情感 | 个人惋惜（46%，簇1）· 严肃追思（19%，簇7）· 悼念+教育（18%，簇8）· 学子惋惜（16%，簇10） |
| 教育关切 | 教育关怀（25%，簇4）· 观点讨论（25%，簇5）· 专业就业（19%，簇9）· 大学学校（16%，簇11）· 基础课业（8%，簇12）· 实用主义（7%，簇13） |

### 1.3 个体交叉机制（用户要求：多类设定 + 个体可跨类交叉）

每个 agent 不再是互斥类的成员，而是持有一个**特征权重向量** w（5 维，和为 1）：

1. **主族**：按 §1.1 配额确定（玩梗 23 / 悼念 29 / 教育 27 / 反思 8 / 吃瓜 13）；
2. **次级族**：按族间邻近权重采样 1 个（80%）或 2 个（20%）非主族：
   - 邻近权重（依据簇共现语义：簇3 反思与悼念共生、簇8 悼念+教育实证、吃瓜与玩梗同为轻卷入姿态）：
     mourning↔reflect 0.35 · meme↔casual 0.35 · mourning↔edu 0.30 · edu↔casual 0.20 · meme↔mourning 0.15 · reflect↔edu 0.15 · meme↔edu 0.10 · reflect↔casual 0.10 · mourning↔casual 0.10 · meme↔reflect 0.05；
   - 每个次级族权重 w ∈ U(0.15, 0.30)，主族权重 = 1 − Σ次级（保证主族 ≥ 0.40）；
3. **个体梗倾向** = Σ w_i × 梗倾向_i（§1.1 数值），分三档写入 persona：高（≥0.45）· 中（0.20–0.45）· 低（<0.20）；
4. **persona 文本** = 生活背景句（主族风味模板，每风味 2–3 变体）+ 次级特质句（权重 ≥0.15 的次级族各一句）+ 表达倾向句（梗倾向三档）+ 熟悉度句（§1.4）。

效果：没有任何两个 agent 权重向量相同；每个 agent 的 persona 明确写出主身份 + 1–2 个次级特质——类间交叉由权重向量承载，而非类目标注。

### 1.4 熟悉度分组（H3 分组变量，与特征族独立）

- 50 低熟 / 50 高熟，**族内分层等比**分配（玩梗 12/11、悼念 15/14、教育 13/14、反思 4/4、吃瓜 6/7）——熟悉度与特征族正交，避免「圈内=教育族」的混淆；
- **低熟**（圈外组）：persona 明确「此前完全不知道张雪峰，对其无既有印象，也不知道其职业背景」，首因印象由本次曝光形成；
- **高熟**（圈内组）：persona 含具体生前认知（讲考研/志愿填报、说话直、风格犀利）+ 态度效价三分：认同 40% / 无感 35% / 有保留 25%；
- T0 基线问卷自评熟悉度作为分组效度检验（v0.1 设计保留）。

### 1.5 分析元数据

`agent_profiles.json`（init/ 目录）记录每 agent：`{agent_id, name, family, flavor, trait_weights, meme_tendency, meme_band, familiarity, attitude_valence}`——H3 主分析按 `familiarity` 分组，特征权重向量用于事后探索性分析（如「玩梗权重是否调节偏移幅度」）。

## 3. 交互与测量规则（沿用 v0.1，摘要）

- 每 tick（=1 仿真日）行为循环：refresh_feed（20 条）→ view_post（≤8 条/日）→ LLM 逐帖互动决策（点赞/评论/转发；玩梗再生产需 is_meme 帖重复曝光 ≥2 次，低熟 agent 首次接触不主动玩梗）；评论必须引用所见内容，禁止凭空生成对逝者的评价；tick 内不作全局自我总结。
- 印象测量：T0（基线）→ 4 ticks → T1 → 4 ticks → T2 → 4 ticks → T3；题目 4 道（印象词 / 熟悉度 1–5 / 印象来源 / 职业印象），认知偏移操作化 = 印象词编码后的集中度（HHI/Top-1 份额）+ 职业印象事实层偏差。
- 设计原则不变：**曝光层可参数化，认知层必须涌现**；**同供给同用户池**（H3 两组在同一 run、同一供给、同一推荐器下比较，组间唯一系统差异是初始熟悉度）。

## 4. H3 实验结构（单 run 双组）

```
hypothesis_3/experiment_1/   ← 唯一 run（本目录）
  100 agents = 圈外组（低熟 50） + 圈内组（高熟 50）
  环境/供给/推荐器完全一致；分析时按 agent_profiles.familiarity 分组
  因变量：认知偏移程度（T1–T3 印象词集中度、事实层偏差相对 T0 的变化）
  检验：组间偏移差异（圈外 > 圈内 → 支持原假设；圈内 ≥ 圈外 → 备择情形成立）
```

原 `experiment_2`（treatment_outsider 独立 run）已删除——两组共存于同一 run 才能满足「同供给同用户池」的归因条件。
