# 锚定式效用公式、参数标定与基线烟测工作总结

## 一、研究定位

本轮工作的目标不是建立可泛化到所有公共事件的统一行为模型，而是重建“张雪峰逝世及后续玩梗兴起”这一具体事件，并以该事件的现实轨迹作为事实基线，研究不同推荐算法与平台治理规则可能造成的反事实差异。

因此，参数具有事件特异性本身不构成过拟合。事实基线越接近本事件的现实过程，后续算法治理实验的参照越可信。需要防范的是对单个随机 seed 的偶然波动进行手工调参，以及为不同算法臂分别调参导致反事实不可比。

## 二、问题识别与机制裁定

旧公式为：

\[
U_{it}=D_{it}R_{it}
\]

其中注意力衰减因子 \(R_{it}\) 会持续趋近于零。即使教育、营销和其他类型在事件前存在常态讨论，长期也会被纯乘法结构机械压至沉默。这与真实数据中W18只是回到事件前量级、而不是所有讨论消失的现象不符。

本轮没有增加“第二波回流”等第三种行为机制，而是在保留沉默螺旋 \(D\) 和注意力衰减 \(R\) 的前提下，将表达效用改为锚定式结构：

\[
U_{it}=B_i+R_{it}(D_{it}-B_i)
\]

\[
D_{it}=1+(\alpha_Ds_i)\tanh\left(1.5\frac{share_{it}-base_i}{base_i}\right)
\]

\[
R_{it}=\exp\left(-\lambda_i\frac{cum\_own_{it}}{15}\right)
\]

当且仅当 \(U_{it}\ge activity_i\) 时Agent发言。

该结构满足以下边界：

- \(R=1\Rightarrow U=D\)：注意力尚未疲劳时，由当周意见气候主导；
- \(R\to0\Rightarrow U\to B_i\)：事件冲击消退后回到常态效用锚点；
- \(D=B_i\Rightarrow U=B_i\)：意见气候位于锚点时，疲劳程度不改变常态效用。

环境中的 \(B_t/S_t/G_t\) 继续作为描述性观测量写入replay，但不参与Agent发言决策。原有的帖子生命周期、曝光饱和、W13官方讣告置顶、事件周议程保底以及“本周Agent帖子下一周才进入信息流”的时序均保持不变。

## 三、冻结参数

全局沉默螺旋缩放参数为：

\[
\alpha_D=0.4296954756
\]

五类Agent的常态锚点和平均疲劳系数为：

| 类型 | 常态锚点 \(B_i\) | 平均疲劳系数 \(\lambda_i\) |
|---|---:|---:|
| 玩梗 | 0.7755 | 1.2430377762 |
| 悼念 | 0.7678 | 2.2820352014 |
| 营销 | 0.82515 | 1.0192411150 |
| 教育 | 0.7412 | 2.4936143468 |
| 其他 | 0.7686 | 4.4294577101 |

当前参数的实际来源为：

- \(B_i\) 根据W05–W12事件前常态供给映射到既有activity分布后固定；
- \(\alpha_D\) 与五类 \(\lambda_i\) 通过统一目标函数，只使用W13–W18进行数值代理标定；
- W19–W22在本轮参数搜索中没有参与选点，原设计将其作为时间留出诊断；
- 类型内的 \(\lambda_i\) 按原个体值同比缩放，保留Agent之间既有的相对异质性。

数值代理的类型发言率RMSE为：拟合期W13–W18为0.0929，留出期W19–W22为0.1276；总量形态RMSE分别为0.0873和0.0912。总量形态的拟合—留出差距较小，但类型构成的留出误差明显更高。

## 四、实验配置与完整性

本轮生成了三种推荐算法、每种三个seed的9份独立配置：

- `anchored_v1_random_s{0,1,2}`；
- `anchored_v1_chronological_s{0,1,2}`；
- `anchored_v1_interest_s{0,1,2}`。

实验规模保持为100个Agent、W12–W22共11周，每个Agent每周最多发1帖。本轮首先运行了事实基线的单seed诊断性烟测：

- run：`anchored_v1_interest_s0_smoke`；
- Agent构成：玩梗19、悼念22、营销23、教育15、其他21；
- 环境周记录：11行；
- Agent周记录：1100行，每周严格100行；
- `step_count=11`，主进程正常退出；
- 日志结论：`Experiment completed successfully`。

该结果只能称为单seed诊断性烟测，不能替代正式9-run结果。

### 5.3 已实现的改进

- W13由悼念主导，玩梗保持相对抑制；
- W13以后供给逐步衰减，在W18/W19附近形成深谷；
- W20以后玩梗快速兴起，悼念保持相对抑制；
- 教育和营销在谷底及第二波期间仍存在少量供给；
- 没有增加针对W19的显式再激活项，第二波由既有真实内容输入、推荐曝光和Agent反馈内生形成。

### 5.4 尚未完全解决的问题

- 玩梗第二波强于真实数据，尤其W20和W21份额过高；
- 模拟W22总量没有继续上升；
- Agent-only口径中，悼念在W19–W22为0，“其他”在尾部也多次为0；
- 当前 \(B_i\approx0.74\text{–}0.83\)，而Agent平均activity门槛约为0.95，因此 \(R\to0\) 时的 \(U\to B_i\) 并不数学保证每一类型每周都有人发言；
- 合并供给图包含真实帖子注入，其总体形态部分由外生输入决定，机制判断应同时参考Agent-only曲线。

## 六、关于过拟合的最终裁定

本研究属于事件特定的历史情境重建。研究目标是以张雪峰事件为事实基线，比较同一事件、同一Agent群体和同一行为参数在不同推荐算法或治理规则下的反事实结果。因此，不要求参数跨事件泛化，五类 \(\lambda_i\) 的事件专属标定具有必要性。

当前锚定式公式只重组了已有的 \(D\) 与 \(R\)，没有增加专门拟合W19的第三机制，结构层面的过拟合风险较低。参数层面仍存在以下风险：

- 6个拟合参数对应一条高度自相关的单事件时间序列，有效信息量有限；
- 公式选择过程已经观察过W19–W22，因此原时间留出并非完全独立的外部验证；
- 当前烟测只有一个seed，而且与代理标定使用相同的兴趣推荐结构和真实语料池；
- 多组参数可能同样拟合事实基线，却对算法治理反事实给出不同结论，即等效拟合或不可识别问题。

综合判断是：事件专属标定本身不应被视为过拟合；真正需要防范的是单seed过拟合和治理结论对参数选择过度敏感。

如果研究目的明确为完整重建本事件，W19–W22也可以纳入事实基线标定，但此后不能再把它们称为样本外验证，而应明确表述为“W05–W22全事件窗口校准”。

## 七、后续实验原则

1. 不根据本次 `interest_s0` 的单次随机波动继续手工调参；应先观察三个interest seed的平均事实基线。
2. 参数只允许在事实基线的interest臂上标定；random与chronological是治理反事实臂，不得分别调参。
3. 一旦事实基线达到预先定义的误差标准，立即冻结公式与参数，再比较三种算法。
4. 除总量面积图外，同时报告Agent-only供给、五类份额、W13峰值、W18/W19谷底、第二峰时点和尾部类型构成。
5. 保留一组拟合接近最优的参数集合进行敏感性分析；如果不同参数组下算法治理结论排序一致，反事实结论才具有稳健性。
6. 正式结论必须来自三算法×三seed的9 runs，并报告跨seed均值和不确定性；本次烟测仅用于验证实现和曲线形态。
