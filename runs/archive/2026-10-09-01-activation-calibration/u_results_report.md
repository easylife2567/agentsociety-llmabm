# U补充检验：结果、八项判断与主实验建议

本轮已完成108个新增固定正文闭环单元，复用9个原规则单元，并重算3个原单元验同。新增108,900次发帖决策机会；矩阵实际耗时187.3秒。全部无LLM、无网络；正式Agent、环境与主批配置保持原样。主项目已采用论文结构，见[OUTLINE.md](../../../paper/OUTLINE.md)。原始逐行动记录和完整统计在[u_results](u_results/README.md)。

**可以支持的结论：低频压零可以通过保留分数期望的最小随机规则消除；门槛、初始化及所测D/R函数改变不消除主要晚期制度分化。不能支持的结论：回流必然或统一放大玩梗；B、D、R是真实心理参数或唯一可识别参数。**

## 一、晚期制度比较

各单元统计W19–W22的玩梗帖总数及其占该四周全部Agent帖的份额，然后对三输入seed求均值。份额是每seed份额的均值，不能用均值计数相除复算；逐seed和范围见effects.csv。以下不包含真实外部帖子。

| 条件 | 随机：帖数／份额 | 时序：帖数／份额 | 兴趣：帖数／份额 |
|---|---:|---:|---:|
| 原规则＋W12发布 | 3.00／10.3% | 43.00／73.3% | 36.67／67.5% |
| 原硬门槛＋W12只读 | 3.33／11.4% | 43.00／73.7% | 37.33／67.0% |
| 分数映射＋W12发布 | 4.00／12.8% | 42.67／70.3% | 37.00／64.8% |
| 候选中心：分数映射＋W12只读 | 4.00／14.4% | 42.67／71.1% | 38.00／64.8% |
| 分数映射＋W13冷启动 | 5.00／14.8% | 43.00／69.8% | 37.33／65.8% |
| 微扰ε=.01 | 2.00／6.1% | 43.00／70.1% | 37.67／64.9% |
| 微扰ε=.04 | 4.00／13.6% | 41.67／71.8% | 37.67／68.0% |
| 门槛基准.90 | 5.00／15.0% | 44.00／68.8% | 41.33／66.3% |
| 门槛基准1.00 | 3.00／10.7% | 41.00／72.0% | 35.00／64.3% |
| D匹配斜率的atan替代 | 3.33／10.7% | 41.67／71.2% | 40.33／66.1% |
| R匹配半衰点的双曲替代 | 2.33／4.7% | 43.33／62.0% | 34.67／46.4% |
| 候选中心去回流 | 8.33／22.4% | 45.33／70.1% | 36.67／64.3% |

所有上述保留回流的敏感性条件，在三seed中时序/兴趣臂的晚期玩梗绝对供给与份额均高于随机臂。这个结论是有限条件下的方向保持，不代表所有逐周差值、峰周、类型排序或数量均保持。双曲R替代使兴趣臂晚期玩梗份额由64.8%降至46.4%，因此注意力函数影响幅度相当明显，应在补充材料报告，并在正文避免“参数选择不影响结果”的措辞。

## 二、低频与初始化

候选保持每人固定A，只在决策时加Uniform[-ε,ε]微扰，并以R=0、feed非空为条件求B，使五类发言概率之和等于原分数行动当量。它给出的非零是跨重复机会的期望，不是要求每一周每一类都有人发帖，也不代表已发现真实心理噪声。

| 类型 | 原分数期望 | 原规则R=0人数 | 候选精确期望 |
|---|---:|---:|---:|
| meme | 0.009333899 | 0 | 0.009333899 |
| mourning | 0.000583369 | 0 | 0.000583369 |
| marketing | 2.625159101 | 3 | 2.625159101 |
| education | 0.285267289 | 0 | 0.285267289 |
| other | 0.071754349 | 0 | 0.071754349 |

全部软映射条件精确求和误差小于1e-10，每配置100,000轮静态随机抽样与理论期望在预定6倍标准误差内相容。这是规则正确性的检验，不是现实效度的独立证明；原均值与候选目标同源。悼念常态期望约每1,714次群体机会才一帖，短仿真内零次完全可能。

W12只读预热不发布Agent帖，真实到达、曝光与累计接触仍推进；事件后从W13开始解释。原发布/只读的2×2比较、W13冷启动都保持晚期主要差异，但随机臂W13悼念由原规则的2/5/5提高至只读预热的7/12/12，说明初始化对早期量级有实质影响，不能笼统写“初始化无影响”。原W12的25–26帖与常态参照5.288不再被描述为验证成功。只读预热是解释目标的设计取舍，不是对W12实际不发帖的现实判断。

沿用旧α_D与λ不等于在候选规则上重新标定。作为事后诊断，W13–W18按类型人口归一化供给RMSE（三seed所有类型/周次合算）：原规则随机/时序/兴趣为0.2115/0.1179/0.1531，候选中心为0.1818/0.1187/0.1534。此诊断未用于择优或拟合，不证明唯一参数有效；若后续采用候选，应明确B新映射、其余参数迁移的来源，而非宣称全部重新估计。

## 三、回流阻断：关键反例与可保留的解释

阻断后九个单元的生成帖曝光严格为零，但全部仍产生晚期玩梗增长。相对候选中心，随机/时序/兴趣的晚期玩梗总量差为+4.33/+2.67/−1.33；兴趣臂差值逐seed为−4/+2/−2，不是三seed一致的正向放大。故“回流是玩梗增长的必要条件”和“回流统一放大玩梗供给”均不受本轮支持。

回流对跨类型可见性更清楚：非玩梗Agent所见feed中的玩梗比例，时序臂由去回流32.8%变为有回流40.7%（三seed皆增加）；兴趣臂19.5%→20.9%（两个seed增加、一个减少）；随机臂5.5%→4.1%（三seed皆减少）。同一反馈环节具有制度依赖的可见性作用。这里没有真实社群网络，只能称跨类型可见性。

可讲的故事是：外部输入与选择性表达足以产生主要表征变化；回流进一步重排后续可见内容，且其作用取决于制度，未必提高玩梗表达总量。候选机制的“能生成”与“去掉就不能生成”是两类主张，不可混用。上述结果要求第四章机制段报告这个边界，不能为保护原叙事忽略阻断结果；是否在完整LLM中不同，必须由新结果回答。

## 四、U组合与组件

兴趣臂中心条件晚期玩梗38.00帖、份额64.8%；旧U=DR为24.00帖、100%；去D为13.67帖、38.2%；去R为25.00帖、11.7%。旧组合的100%来自其他类型退场，玩梗绝对量同时下降，不能按份额认定重组更强。去R保持更多其他类型活动且玩梗量下降，提醒R回归B也可解除原有抑制，不是单向降低所有发言。旧U与去B数学等价，不能当成两份独立证据。三组件检验只覆盖兴趣臂数值代理，不能推广为三制度的完整LLM消融结果。

## 五、八项质疑：怎么回应、放在哪里

| 问题 | 本轮判断与证据 | 论文组织 |
|---|---|---|
| 1．0.95 | 建模门槛基准；.90/.95/1.00保留主要模式，非心理临界值验证 | 正文说明固定门槛，数值与敏感性入S3/S4 |
| 2．文献迁移 | 文献支持机制动机，本项目变量/函数是新增操作化；D/R替代保留方向但R幅度敏感 | 正文短说明迁移假设，原文对应及全式入S3；不得说直接照搬原公式 |
| 3．B/D/R标定 | B有明确尺度和常态目标；已有窗口/尺度检查支持有限相容；α_D/λ沿用同一来源，三制度共享，不能证唯一 | 正文交代数据窗口、W13定尺度与共享；搜索/参数/迁移限制入S3 |
| 4．低频压零 | 原规则有结构性零；候选精确保留分数期望，动态模式保留；候选尚未正式采用 | 正文一句说明最终采用的规则；完整B求解/随机性入S3 |
| 5．U组合 | 三组件在兴趣臂有可分辨作用；B不能保证有限人口下每类非零，R不必单向抑制 | 正文U式和传播含义，旧组合/组件表入S4 |
| 6．初始化 | 主要晚期方向保留，但早期悼念量级敏感；推荐明确W12预热与事件后目标 | 正文简述阶段，初始化比较入S3/S4，若讨论早期量级需正文报告 |
| 7．标定/验证 | 回顾性机制重演；W19–W22有历史咨询，不是独立预测留出；代理不能充当LLM验证 | 正文交代证据身份，完整数据使用历史入S3 |
| 8．反馈支持 | 去回流仍增长，统一正向放大不成立；对跨类型可见性具有制度依赖作用 | 正文结果核心必须报告；完整干预矩阵入S4 |

## 六、下一步主实验的可执行建议

建议把ε=.02分数期望映射＋W12只读预热作为待采用主规则：它直接消除结构性压零，明确事件后解释范围，不是按最佳拟合挑选。保留原规则作为一项关键对照。候选本轮只在run脚本中实现；正式Agent、初始化配置和论文方法尚未切换，需要选择性采用和正式位置验收。若保留原规则，也能研究事件后机制，但须明确低频近似和W12边界，不能声称四类非零常态已恢复。

完整LLM阶段优先：选定规则的三制度×三seed主批；匹配规则的去回流三制度×三seed，以直接检验制度依赖反馈。原规则对照和选定R函数敏感性可按剩余预算限定，不需要把108条件全量LLM复跑。具体调用预算尚未授权，本轮不启动。LLM干预不能预设要“修复”本轮回流反例；若仍成立，就按制度依赖反馈写论文。

## 七、核验与恢复

三原单元3300条原字段逐值相同；分析从117个原始审计独立重算数量，核对噪声、决策、单人周次数、哈希与回流零曝光。真实累积、未来时间、同批发布资格在执行过程断言。准确Git对象独立导出源码后，静态全部表及候选中心/去回流interest s0两单元2200条记录、周统计完全恢复；不把两单元恢复称全矩阵复跑。

首轮复现失败仅为直接读取profile的十进制B与原映射结果约1e-16差异；统一使用既有标定精确值后全原字段复现成功。原失败目录与日志保留，未更改科学条件。冻结协议、脚本、来源和验证分别见[u_protocol.md](u_protocol.md)、[manifest.json](u_results/manifest.json)、[analysis.json](u_results/analysis.json)、[u_recovery.json](u_recovery.json)。
