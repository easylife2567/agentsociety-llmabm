# 离线实验冻结输入

父级入口为[run README](../README.md)，冻结时刻、基线、逐文件SHA256及依赖版本见[experiment_manifest.json](../experiment_manifest.json)。本目录不含凭据。

| 直接资产 | 用途 |
|---|---|
| `observations.json` | 工作簿按周×类型的帖子、去重作者、队列活动聚合及队列人数；不保留作者身份 |
| `hypothesis_4/` | 基准周曲线与experiment_2九个配置、外部采样及初始历史池的冻结副本 |
| `custom/` | 原词表vocabs冻结副本，供正式环境的正文倾向评分与判类 |
| `README.md` | 来源与恢复边界 |

原始78MB工作簿保持在正式数据位置，只读校验；路径、SHA256、有效/缺作者计数已登记。恢复全部窗口检验与闭环代理只需这里的聚合及素材，无需依赖该工作簿或其他活跃run。重新审计原始聚合则需要取得SHA256一致的工作簿。

去重与队列定义：剔除“存疑”；作者缺失只从作者统计排除；原标定使用UTC ISO周界。W12–W22观察到的单类型作者定义固定队列，再统计其W05–W12活动。这是观察样本的条件队列，不能识别未发帖人群。
