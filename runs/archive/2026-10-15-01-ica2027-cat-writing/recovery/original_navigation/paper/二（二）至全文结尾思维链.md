|---|---|
| （一）模型与实验设计 | 将传播竞争落实为固定作者群体、表达判定和内容回流的模型，并通过共同条件下的制度对照与组件消融建立可比较的实验设计。 |
| （二）策展制度下的表征轨迹分化 | 从平台观察提供的节奏与幅度维度进入模拟比较，依次呈现三种制度的时间轨迹及晚期数量、份额差异，再将结果交给过程解释。 |
| （三）表征分化的传播反馈机制 | 沿个人所见进入表达判定、新表达成为后续接触条件、组件干预改变循环的路径，说明供给份额与可见位置如何重组并形成分化的表征轨迹。 |

## 五、讨论与结论

**整章一句话：** 汇合现实观察与模型过程，依次深化表征重组、选择性表达循环和策展制度作用三个问题，说明解释的适用范围，最终将全文收束为不同声音如何随时间获得并维持公共位置。

| 小节 | 整节一句话 |
|---|---|
| （一）时序演化中的公共表征重组 | 将关注度变化推进为表达构成与呈现方式的变化，并通过共同顺序中的平台分化深化对逝者表征时序演化的理解。 |
| （二）选择性表达与公共表征的循环生成 | 以公开表达连接个人接触与后续信息环境，结合参与时机、接触历史及群体间供给变化，解释公共表征如何在循环中生成。 |
| （三）策展制度与平台差异的机制理解 | 将策展理解为对表达持续与再次可见机会的组织，通过接触和参与的安排连接制度比较与现实平台差异，并提出纵向评估的方向。 |
| （四）研究局限与后续方向 | 从样本与测量层次、模型条件与比较范围两方面界定解释边界，并提出连接文本与受众、拓展情境及区分机制作用的后续路径。 |

| 序号 | 正文位置 | 一句话思维链 |
|---|---|---|
| 18 | 章首：从两项研究进入综合讨论 | 将逝者公共形象置于纪念、讨论与玩梗再利用的动态关系中，汇合平台分析与仿真的互补认识，并以公共表达的时间组织统领后续讨论。 |
| 19 | （一）第一段：从关注轨迹进入表征轨迹 | 连接关注度衰减与数字记忆流通两类研究，说明持续被提及可以伴随不同表达相对位置的变化，从而把关注数量推进为人物如何被呈现的问题。 |
| 20 | （一）第二段：共同顺序中的平台分化 | 从两平台共同顺序与晚期差异出发，结合逝后迷因的文化作用，说明玩梗与悼念及其他讨论之间的相对变化如何重组人物的公共呈现方式。 |
| 21 | （二）第一段：既有群体如何重组公共表达 | 以固定作者群体之间参与和可见位置的重新分配连接策展流框架与反馈回路视角，说明公开发表的表达如何成为后续个人信息流的内容来源并持续生成公共表征。 |
| 22 | （二）第二段：参与时机与接触历史的共同作用 | 从组件比较提炼当前响应、累计接触与多类作者持续参与的共同作用，说明一个群体较晚获得突出位置取决于不同声音在各阶段的参与及其留下的后续接触条件。 |
| 23 | （三）第一段：制度如何组织传播的时间条件 | 由时序与兴趣制度均可形成晚期供给集中的结果，结合算法与社会动力相互作用的研究，将策展的作用概括为通过内容选择、保留和再流通组织持续表达及再次可见的机会。 |
| 24 | （三）第二段：从制度比较连接平台观察与实践 | 通过接触和参与的组织方式连接平台观察提出的问题与受控制度比较提供的解释，并将其推进为对不同声音持续程度、供给份额和跨群体可见性的纵向考察。 |
| 25 | （四）第一段：观察材料与表征测量 | 明确现实样本、仿真输入及观察层次的范围，提出通过生成帖语义编码、用户理解的纵向测量和跨事件平台比较，进一步连接作者参与、文本含义与受众理解。 |
| 26 | （四）第二段：模型条件与机制比较 | 交代固定群体、共同参数、完整制度比较、兴趣制度内消融及分批生成的条件，进而提出同期对照与分环节操纵，以检验稳定性并区分各机制的作用。 |
| 27 | 章末：回到逝者被如何记住 | 将时序与平台差异同接触、参与和再分发相连接，凝练策展组织接触、表达塑造后续接触的循环认识，并以不同声音如何获得和维持公共位置回答逝者被如何记住。 |
