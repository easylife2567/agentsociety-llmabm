# timestamp 推进决策的独立复核：四格诊断与无LLM数值验证

## 本次回答什么

用户要求评判：本 run 的四格到达时机诊断与无LLM数值验证结果，能否支撑按 timestamp 方案继续向下做（timestamp 作为到达规则，在此基础上实施日期/身份输入修复、拒答分账与测量桥接，之后另行决定是否跑新的 LLM 主实验）。

**复核结论：有条件支持。** 支撑继续推进的不是"四格实验证明 timestamp 更优"，而是另外两条与该比较无关的证据：时间有效性在设计上成立（preload 按设计整周提前可见、timestamp 实测未来曝光为 0），以及内容与记账缺陷在任何到达规则下都必须修复。四格方向比较只能读作"本seed内未被推翻"，不是对 timestamp 优越性的经验背书。

本文件是复核记录，不改写实验结果、不改判据、不新增实验；结论已在任务 README 登记。

## 方法与依据

- 13 个隔离子 agent 两阶段执行：7 组独立核查（主指标、生产端、处理与泄漏、数值验证、知识来源、测量口径、出处一致性）→ 4 个评判视角（构造效度、决策质量、阻塞项、统计支持力）→ 综合裁决 → 红队对抗。
- 全部数字从原始账本（四个 run 的 `agents/*/AGENT.json`、`ENV_STATE.json`、`full_audit.json`、`replay/`）与正式分析资产重新计算，不转述报告文字。
- 91 条断言中 89 条 confirmed、2 条 partial（均为措辞精度），无 refuted；614 条输入哈希与磁盘逐一匹配；四份 `full_audit.json` 零失败；数值重放 2,200 次行动 U 误差 0、判定不一致 0。
- 全程未调用模型、未联网、未修改正式资产；临时输出仅在 /tmp。

## 核查确认的关键事实

1. **配置可比**：四份冻结配置递归 diff 后唯一差异是 `arrival_mode`（preload/timestamp）与 `recommendation_algorithm`（interest/random），seed、人口、行动表、参数、注入路径逐值一致。批内对照干净。
2. **处理真实发生**：preload-interest 未来曝光 1,811/11,000 槽（16.46%）、受影响行动 764/1,100（69.45%）、实际生成上下文含未来槽 232；preload-random 975（8.86%）/468/120；两个 timestamp 全为 0。这排除了"两条件无差异"的无效诊断分支。
3. **时间有效实现成立**：`custom/envs/curation_arrival_schedule.py` 在 timestamp 模式按 `available<=cutoff` 注入、Agent 帖次周释放；审计器仅对 official/timestamp 把未来曝光记为 forbidden；四份审计零失败；数值重放未来曝光 0。代码、审计、重放三层一致。
4. **主结果数字全部复现**：O/E/Y/S/A/O÷E 四行、五项预登记对比（+2.2400 / +1.5575 / −0.6825 / −0.8525 / −0.1700）、30.47% 收窄、恒等式分解（2.1812+0.0588 / 1.4822+0.0753）与正式资产 `summary.json` 逐位一致。
5. **收窄由候选池通道驱动**：池期望差收窄 0.6990、残差反增 0.0165；interest 臂主导（降 0.8525 vs random 0.1700）；interest 后期池内玩梗占比按中位数由 22.79% 降至 11.50%，random 由 3.93% 降至 2.56%。该结论支持"先检查候选池构成与反馈"，不支持"兴趣匹配机制被验证"。
6. **生产端链条完整**：W19–W22 发布 69/53/28/29、玩梗作者 50/32/4/3、参与率 65.79%/42.11%/5.26%/3.95%（分母 19×4=76）；周轨迹 W20 12 比 1、W21 19 比 13、W22 19 比 18；三套 random"发言决定数=成功发布数"成立。玩梗作者起量更晚为描述性事实。
7. **数值验证支持继续修输入**：两 timestamp 原轨迹各 1,100 行动完整复现；屏蔽 agent79/W16 已确认拒答后 213 发布、16 次判定变化（11 升 5 降）、599 次前五条上下文变化、744→757 曝光；383 份实际上下文缺逐帖发布时间，1,915 槽原型在 5×120 预算内可行；周界影响 ≤0.79 个百分点。
8. **问题帖对主指标影响为零**：19 条已确认问题帖的作者类型均非玩梗，按指标定义不进 O；极端假设全部计为玩梗时，任何预登记对比符号都不翻转（交互最多缩 16%）。问题帖主窗口直接曝光 0/0/52/8 集中在 random 臂，不会虚增 interest 的差值。
9. **报告诚实性通过**：单 seed 描述性、无显著性、"30.47% 仅描述本次实现"、"暂缓严格时间有效且知识无污染生成机制已验证"、同候选池消融待做等边界均如实声明；未换窗口、未发明事后阈值、失败证据保留。

## 四个评判视角

四个视角独立给出同一裁决 **supports_with_conditions**：

- **构造效度**：batch 内对照干净，但结果测的是"含候选池与反馈的完整制度总效应"，不是纯兴趣排序；主指标 O 混合"外部帖冻结标签 + Agent 帖作者身份"两类语义，各格构成比例不同，只能作供给群体可见度测量。
- **决策质量**：决定含经验部分（提前阅读实测存在、方向保留）与设计/合规部分（论文主张模拟真实到达则不能周初预载）；后者是建模约定判断，报告已如实标注，未冒充经验验证。替代方案（保留 preload、重标定 D/R）被公平处理。
- **阻塞项**：无一项缺陷推翻"到达时机需要修正、方向保留"；(b) 类阻止升格为主实验的是日期输入缺陷、19 条问题帖、拒答被发布；(c) 类与到达时机正交、可并行修复的是作者类型≠正文语义、词表主类与信号分歧、现实与仿真口径不可比。
- **统计支持力**：四格 z 值均在 ±1.7σ 内（含忽略池演化与反馈的乐观假设），30.47%、参与率、A 符号翻转都只能作单次实现描述；论文级主张还需多 seed、预登记检验统计量与最小有意义效应量、尊重闭环反馈的零模型。

## 红队的修订（已采纳）

红队裁定"结论保留、表述收紧"，五点修订：

1. "方向性诊断门通过"应降级为"本 seed 内方向未被推翻（弱通过）"，并注明：interest 臂信号集中在 W20–W22（W19 两臂均为 0）、保留差约 95% 来自池期望通道、random 臂残差翻转（约 23 槽/0.574 个百分点，z<1.5）在抽样噪声内。
2. 池占比引用需标口径：中位数口径 22.79%→11.50%（`summary.json`）与逐行动均值口径 26.17%→18.05%（本次复算）方向一致、幅度不同，两套数字并存须标来源。
3. 新 LLM run 需要事先写明决策规则：何种结果视为修复后 timestamp 方向确认、何种结果需要回头重审 timestamp 与 preload 的取舍，不能停留在"不承诺方向保留"。
4. 测量桥接的独立打标费用、输入发送范围与调用量按 `2026-10-03-01-input-accounting-plan.md` 单列为独立授权项，不混入仿真预算。
5. 标题与结论须显式说明承重基础是"时间有效性（构造性）+ 内容缺陷（任何规则下都需修）"，防止把弱通过诊断读成经验背书。

## 最终裁决

**支持**：以 timestamp 为到达规则继续推进；四格诊断与数值验证作为诊断证据；19 条问题帖、agent79 拒答、agent56/43 相对日期实例作为修复的必查验收样本；数值复现作为可回归的基线。

**不支持**：机制已验证、timestamp 更接近现实、30.47% 是稳健效应量、作者份额可作正文语义份额、fixed_supply 的 213 或 closed_support 的 143 是修复后预测、当前两臂是已验收主实验、继续推进无需新授权。

**前置条件**（与 `2026-10-03-01-input-accounting-plan.md` 一致）：

1. 日期/身份输入修复，以实际 messages 含带时区发布时间为验收，通过独立阅读核查；
2. 拒答分账：`speak=true, posted=false`、无 ID、无供给回流，互斥守恒式成立，审计单列拒答；
3. 测量桥接：冻结 120 条现实样本与 383 条 timestamp 正文的同一判类器输入契约与混淆矩阵；
4. 以干净基线 `abbbcdb` 保存最终 patch，独立审查后先离线功能验收；
5. 所有量级引用保留"单 seed 描述性"标签；
6. 新增 LLM 主实验（最小 2×100×11、6 小时候选预算）须单独授权与预算锁定，原四格 24 小时额度不自动延续。

**未决问题**：新增 seed 或同候选池消融后方向是否保留；收窄是否可由单一主导作者或供给伪影解释；239 条未核查正文（占 794 的 30%）不默认无问题；问题帖曝光计数只统计整条被显示，不追踪后代，不能据 interest 后期直接曝光为 0 宣告污染无影响。
