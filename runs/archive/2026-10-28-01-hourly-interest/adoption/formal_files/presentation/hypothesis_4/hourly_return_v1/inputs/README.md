# 冻结现实效标与DTW定义

本级三项数据与探索阶段原文件逐字节一致，供正式离线复算使用。历史来源路径保留在审计JSON内部，仅作溯源，不作为加载依赖。输入哈希冻结在上级contract.json和正式运行manifest。

| 文件 | 用途 |
|---|---|
| reality_week_boundary.csv | W12–W22×五类共55行；上海周为主，UTC为补充；全量现实非噪音份额 |
| reality_measurement_audit.json | 冻结现实整数计数、原始数据来源与边界核验 |
| dtw_method.py | 原约定DTW函数：五维欧氏距离、±1周、最小累计路径后按路径长度归一化 |

DTW函数保留原字节；不得运行历史绘图脚本中硬编码胜出结论的主程序。
