# 原始执行与验收证据

本级原件复制时保持字节，历史路径、状态及授权不改写。当前实际科学矩阵由[上级manifest](../manifest.json)解析，不从历史计划启动运行。

| 直接目录 | 用途 |
|---|---|
| pilot/ | seed0原计划、范围修订、实际状态、原始镜像来源及额外账本；撤回时序只留执行事实、不进入科学矩阵 |
| seed_extension/ | 新增18次原计划、状态、完成表、原始镜像来源及独立额外账本 |
| analysis/ | 历史时序复用审计、原分析合约及独立复算原件 |

上级manifest的source_sha256锁定本级原件。内部旧绝对路径只是证据文本；正式分析只校验这些原件的SHA，实际原始数据从上级30项矩阵读取。
