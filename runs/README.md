## 使用约定

- 新任务使用 `YYYY-MM-DD-NN-NAME/`，同日期编号递增。
- 任务 README 维护本级资产、目标、进度和交接；报告按主题更新，不另建 tracker。
- 新任务脚本、规划、patch、报告留任务目录；`tmp/` 不入 Git，正式证据不能只放临时目录。
- 正式代码、配置与结果仍使用 AgentSociety2 对应目录；用户新增的 data/ 继续存放实验预处理数据。这里只做引用，不迁移或复制这些资产。
- 任务目录增删、改名或活动入口改变时更新本索引；子任务细节只改其 README。
