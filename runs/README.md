## 使用约定

- 决策主题目录使用 `YYYY-MM-DD-NN-NAME/`，同日期编号递增；同主题持续维护，不按每轮对话拆目录。
- 主题README维护决策范围及本级记录索引，不维护实验实时进度或执行交接。
- 记录明确区分用户采纳、否定与尚待决定的建议，注明理由、证据路径和适用边界；无需复制整段对话或完整实验报告。
- 正式工作状态、方案、代码、配置和结果查对应官方目录README；用户新增的data/继续存储预处理数据。
- 主题目录增删、改名或导航属性改变时更新本索引；主题内文件变化只更新其README。
