# 正式位置验收

本目录记录实际正式路径执行结果，不用隔离区通过结果冒充落地验收。

- formal_schema.json：官方九配置/schema/steps、冻结输出和实际custom模块来源。
- extraction.json、extraction.log：12单元13200次机会的replay/环境/Agent交叉核对。
- mechanism.json：D/R逐周及同人同周原始记录、34次去R损失和公式性质。
- final_verification.json：27项原始主指标复算、5394项来源哈希、零周/图表/字体/网络/账本。
- adoption_verification.json：正式副本与原始源文件字节一致、派生表数值一致、现有主工作区差异边界和本级链接。
- artifact_integrity.json：最终采用文件的SHA256清单，不哈希自身。
- template_and_exports.json、dependencies.json：指定模板身份、导出及现有工具链，不表示新安装。

原私有harness回执不迁移为主项目通过记录；本轮没有额外模型审阅或正式validate-synthesis签署。
