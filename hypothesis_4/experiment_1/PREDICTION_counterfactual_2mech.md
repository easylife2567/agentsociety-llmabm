## 1. 为什么要做这一步

正式 9-run 批跑已完成（`results/`），已证「算法策展塑造**玩梗类**表征的二波形态」。
下一步是**机制归因**：Agent 只由两条规则约束（`U = D·R ≥ activity`），
所以问"到底是什么在驱动二波"，等于问 **D 与 R 各自贡献多少**。

做法沿用本工作区既有流程：**先用与真机同构的代理算出预测数据、出图、写下预言，再跑真机**。
与上一轮 `proxy_predict.py` 完全同一套：直接调用 `calibrate_speak.simulate`（单一实现，
不复制装配代码），只把 LLM 内容生成换成实测倾向分画像。

**新增的只有两个开关**（`calibrate_speak.simulate` 的 `spiral_mult` / `decay_mult`）：

- `spiral_mult × s`，取 0 → `D = 1 + 0·tanh(·) ≡ 1`（**精确消融**，非近似档）
- `decay_mult × λ`，取 0 → `R = exp(−0·x) ≡ 1`

默认均为 1.0，即现状。**已做回归检验**：默认路径重跑 `proxy_predict.py`，
CSV 与改动前**逐值完全一致**，既有任何结论不受影响。

## 2. 臂结构：2×2 消融（挂在 interest 臂）

| cell | 沉默螺旋 D | 注意力衰减 R | U | 说明 |
|---|---|---|---|---|
| **D1R1** | 开（s 原值） | 开（λ 原值） | D·R | 基线 = 现有 `interest_s{0,1,2}` |
| **D0R1** | 关（s≡0） | 开 | R | 只看疲劳动力学 |
| **D1R0** | 开 | 关（λ≡0） | D | 只看意见气候动力学 |
| **D0R0** | 关 | 关 | 1 | 纯门槛，**零动力学参照** |

选 2×2 而非单机制消融的原因：D 与 R 是**乘性耦合**（D 正是把 agent 抬过 R 衰减后门槛的那个东西），
交互项本身是要回答的问题之一；且 2×2 已包含两档单机制消融，信息严格更多。

## 5. 核心预言：两机制是**双重分离**，不是一个放大器加一个减震器

拆开绝对量后，结论比份额本身更清楚（W22）：

| | 玩梗帖数 | 总产量 | 玩梗份额 |
|---|---|---|---|
| D1R1 基线 | 18.8 | 31.1 | 0.603 |
| D0R1 关螺旋 | **0.0** | **3.8** | 0.000 |
| D1R0 关衰减 | **18.5** | **56.1** | 0.331 |

> **① 沉默螺旋 D 管"分子"**：关掉它，玩梗**自己不再产出**（18.8 → 0.0），
> 且整个话语场塌缩（31.1 → 3.8 帖/周）。
> **D 不只是放大器，它同时是玩梗二波的**发生条件**与话语场的**自维持机制**——
> 没有 D，`U = R` 单调衰减，疲劳把所有人逐个拖到门槛之下，无任何东西能把表达重新抬起来。
>
> **② 注意力衰减 R 管"分母"**：关掉它，玩梗绝对产出**几乎不动**（18.8 → 18.5，差 0.3 帖），
> 但其他类型不再退潮 → 分母几乎翻倍（31.1 → 56.1）→ 份额腰斩（0.603 → 0.331）。
> **R 对玩梗份额的贡献几乎完全是分母效应，不是分子效应。**
>
> **③ 强正交互（W22 +0.464）**：D 的效应高度依赖 R 是否在场
> （D|R开 +0.603 vs D|R关 +0.140）——正因为 R 在持续往下压，
> D 的共振放大才是"把 agent 重新抬过门槛"的那个东西。两者是配套的，不能各自单独解读。

**④ 零动力学参照（D0R0）**：U≡1 时模型退化为纯门槛——固定 63 个 agent（activity ≤ 1.0）
每周恒定发 63 帖，玩梗份额恒为 0.190 = 12/63 = 群体基数。
**没有任何动力学**。这反过来说明：基线的全部时间结构（W13 冲击、深 V 退潮、W20 起爆）
都是由这两条规则生成的，不是注入池或门槛带来的。

## 6. 可证伪的判据（跑完真机后逐条对照）

| # | 判据 | 预测 | 证伪条件 |
|---|---|---|---|
| P1 | 关 D 后 W20–W22 玩梗份额 | ≈ 0（≤0.05） | 若仍出现二波（>0.15）→ D 非必要，模型解释力归零 |
| P2 | 关 D 后 W22 总产量 | 塌缩（≲ 10 帖，基线 ~30） | 若总量持平 → "自维持"论断不成立 |
| P3 | 关 R 后 W22 玩梗**帖数** | 与基线持平（±3 帖） | 若显著下降 → R 也在分子上起作用，双重分离不成立 |
| P4 | 关 R 后 W22 总产量 | 显著高于基线（~1.8×） | 若不升高 → 退潮不由 R 驱动 |
| P5 | 关 R 后 W22 玩梗份额 | 明显低于基线但非零（0.2–0.45） | 若与基线相当 → 分母效应不成立 |
| P6 | 双关 cell | 恒定、无时间结构、份额 = 群体基数 0.19 | 若出现任何峰谷 → 尚有未识别的动力学来源 |
| P7 | 交互项 W22 | 显著为正（>+0.3） | 若接近 0 → D 与 R 可各自独立解读 |

**注意 P1/P2 是本预测里最强的断言**（"关掉 D 话语场会塌"）。它与直觉相反
（消融一个放大机制不该让讨论消失），故它也是最有信息量的一条——
**若真机复现，说明沉默螺旋在本模型里承担的是"表达的自维持"，而非"表达的加成"。**

## 7. 已知偏差与解读边界（判断时必须扣除）

1. **代理无 LLM 内容生成**：预测的是**行为机制**的净效应；真机里内容层反馈
   （梗变体新鲜感、内容可得性）会调制其幅度，方向应一致、幅度可能有出入。
2. **相位/营销偏差**沿用 `proxy_predict.py`：二波起爆略滞后、营销段系统性偏高
   （平均 |差| 0.21）。这些是**水平**偏差，不影响**差值**符号。
3. **代理用单一注入样本**，不含真机 seed 间的注入池重采样方差；真机 3 seed 的 sd 更大，
   故判据 P1–P7 都按**方向 + 粗量级**判定，不设窄区间。
4. **D0R1 的"塌缩"读数是模型结构的外推**：`U = R` 无上抬项 → 单调衰减是**数学必然**，
   不是涌现结果。真机若因 LLM 内容层或其他未建模项提供了上抬，会偏离此读数——
   这本身是"模型是否缺一个机制"的检验，应如实记录而非调参掩盖。
