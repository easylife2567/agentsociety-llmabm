## 一、两个问题（用户提出）

1. **老帖霸屏**：兴趣推荐缺少"老帖冷却"机制，agent 反复看到同一批高匹配老帖。
2. **W18→W19 发言悬崖**：单个 agent 看到 1 条玩梗帖就开始玩梗；18 个玩梗 agent 的
   发言率从 0.0（W12–W18）一步跳到 1.0（W19–W21），之后恒为 100%，增量不呈渐进。

## 三、因果链（诊断结论）

### 第一段 → 老帖霸屏

1. `_assemble_feed` 的候选集是 `sorted(self._posts)` —— 全历史档案，从不删除、无窗口。
2. 排序里唯一的年龄项是**加性加成** `γ·max(0, 1−age/8)`（`_interest_rank`）：age≥8 周后
   加成归零，但帖子本身不降权，仍以 `α·T` 竞争；而倾向分 T（命中次数/(字数/50)）实测
   p90 可达 7.4，比 γ=0.5 的加成大一个数量级 → **"老而匹配"永远赢"新而略不匹配"**。
3. `exposure_mode="none"`：同一个帖子可以无限次重复进入同一个 agent 的 feed
   （`_seen_by_agent` 有记账但未启用）。

### 第二段 → 同步悬崖

4. **打分里没有任何区分"同类型两个 agent"的项**：唯一的 agent 相关量是 `atype`（取哪一维
   倾向分），噪声仅 ±0.05 而分数跨度 0–14 → 排序结果与具体是谁无关。
   实测：五类的 `share_own` 全部只取 0.00 或 1.00，**逐 agent 标准差 = 0.00**，
   即 18 个玩梗 agent 每周拿到的是**同一份 top-10**（100 人群体实际只有 5 份 feed）。
5. 于是 D（`1 + s·(share_own − base)/base`）的输入只剩两个端点：share=0 → D=−5.67 →
   clamp 到 0.05；share=1 → D=6.47 → clamp 到 2.0。**"40 倍开关"不是 D 的公式问题，
   而是它的输入退化**：D 在 share ∈ [0.03, 0.36] 上连续且强梯度（斜率 6.67），
   但该区间从未被访问。
6. W19 的触发器只是**当周注入的 1 条高倾向分玩梗帖**（`injected_meme(W19)=1`）：
   因排序与 agent 无关，它同时进入全部 18 个玩梗 agent 的 top-10 → share 0→0.1 →
   D 0.05→0.467 → U=1.40 > 全部个体门槛（0.795–1.133）→ 全员发言。
   **G 在 W18/W19 都是 3.0，所以悬崖 100% 来自 D，与 G 无关**
   （chart4 原标题"涌现增益 G 释放后 W19 起爆"的归因是错的）。
7. 开口后被正反馈锁死：agent 帖短（60–150 字）而注入帖长（500–2000 字），而倾向分按
   "命中/字数"归一，agent 帖倾向分系统性偏高（实测 meme：agent 帖 p90=5.38 vs 注入帖
   2.83）→ 玩梗 agent 自己的帖挤占彼此的 feed → share 稳定 1.0 → "后面几周一直在发言"。

### 不是原因的因素（记录以防误改）

- 注入总量 250：W19 实际只注入了 1 条玩梗帖，不是"10 条梗贴占满视野"。
- 决策确定性本身：门槛带再宽也追不上一步 9.3 倍的 U 跳变。
- D 的公式/clamp：它只是忠实反映了一个退化的输入。

## 四、被实测排除的改法（避免重走）

在真实 892 帖池上重放 interest 臂（精确复现 W20–W22 的 share_own = 1.00、sd=0）：

| 改法 | 18 个玩梗 agent 的 share_own（W20/W21/W22） |
|---|---|
| 现状（确定性 top-10） | 10/10/10（sd=0） |
| + 帖子生命周期（half=1.5 周、过期退场） | 10/10/10 |
| + 逐 (agent,帖) 确定性乘性抖动 ±20% | 10/10/10 |
| + 抖动 ±30% / ±50% | 10/10/10 |

**原因**：只要"取分数最高的 k 条"这个操作还在、而高分帖数量 ≥ k（W20 19 条、W22 68 条），
选出的集合就与 agent 无关。**必须动"选择"这一步。**

另测：硬性"每帖每周最多推给 C 个 agent"的曝光上限会饿死早期 feed —— W12 仅 47 条帖，
C=2 只供 94 个槽位而当周需求 1000 槽位；且 C=1/2/3 会把五类气候一起压到 0.1–0.3，
沉默螺旋机制失效。

## 六、遗留问题（冒烟后必须复核，可能回到用户裁定）

1. **G 仍顶在 3.0** → 单 agent 的触发仍是"看到 ≥1 条玩梗帖就够"（share 0.1 → U=1.40 >
   门槛 1.13）。本轮修完后曲线预期从"0→18 一步"变成"2→12→18"两三档，**不是完美渐进**；
   要真正渐进需动触发层（降 G，或按类型调 spiral s / 阈值）。
2. **气候从 {0,1} 变成有梯度后，D 的中性点改变**：其他四类的 share_own 会从恒 1.0 降到
   0.3–0.5，其 D 同步下降（实测悼念 D 从 2.0 → 1.4，W21 后跌到 0.5）→ 悼念峰的时长与
   反事实臂的操纵力需在冒烟里复核。
3. 倾向分的长度归一化偏袒短帖（见 3.7），会放大自反馈。本轮不改，记为 known issue。
