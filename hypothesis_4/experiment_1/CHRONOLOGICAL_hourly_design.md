# 小时级 chronological 推荐算法设计与代理预测

**日期**：2026-09-14  
**状态**：设计、配置与离线校验已完成；正式 run 尚未启动  
**对应主实验**：`anchored_v1_chronological_s{0,1,2}`

## 1. 算法定义

chronological 是一个独立的纯时序制度。Agent 在自己的行动时刻只能看到此前已经发布的
帖子，平台将全部可见帖子按精确 `event_time` 从新到旧排列，返回最新 10 条。它不使用：

- 帖子生命周期或退场线；
- 兴趣匹配、热度或累计曝光权重；
- 官方置顶；
- W13 哀悼保底。

因此，官方讣告若进入最新 10 条，是因为它在时间上足够新，而不是因为平台给它保留槽位。
这使 chronological 只操作“新近性”一个策展原则，不再借用 interest 的候选池制度。

## 2. 真实帖与 Agent 帖如何进入同一时间轴

真实帖保留数据中的精确 `published_at`，统一换算为 Asia/Shanghai。本实验人工加入的唯一
官方讣告没有抓取时间，预登记为 2026-03-24 20:00（正文称“今晚”，且晚于文中 15:50
死亡时刻），避免用 pid 或代码执行顺序替代发布时间。

每个 Agent 每周仍只行动一次。行动时刻从事件前 W05–W12 真实帖的 168 格“星期×小时”
联合分布抽取，固定 `ACTION_SCHEDULE_SEED=44`。这张 100 人行动表在三个 chronological
seed 中完全冻结：每周共有 63 个至少一人行动的小时，11 周共 693 个同步批次。

同一小时的所有 Agent 读取同一份批次前帖子快照，彼此看不到本小时刚生成的帖子；本批次
全部 Agent 决策结束后，新帖统一写入时间轴，后续小时的 Agent 才可看到。由此消除了线程
调度和 Agent id 顺序造成的伪时序，同时保留真实的跨小时扩散。

实现采用事件驱动：没有 Agent 行动的小时直接跳过，不产生空批次。它与逐小时跑 1848 次
在观测语义上等价，但只需 693 个引擎批次。非当前小时 Agent 在 `Agent.step()` 最前面返回，
不访问 Env、也不调用 LLM。Env 在小时级推进，在周末把全部小时批次聚合为一行周度 replay，
所以正式结果仍是 W12–W22 共 11 行，可直接与 random 和 interest 比较。

## 3. 三算法独立性的含义

三个算法共享研究对象、Agent 人口、锚定式表达模型和各 seed 的真实帖样本，但不必共享
候选池规则或行动调度机制：random 是截至当周全历史均匀抽样；chronological 是精确时间
到达与最新 10 条；interest 保留自己的生命周期、兴趣比例抽样和议程位。比较的对象是三种
完整且彼此独立的平台策展制度，而不是同一候选池上只替换一个排序函数。

## 4. 离线代理预测

预测脚本 `predict_chronological_hourly.py` 不调用 LLM，只把 Agent 正文抽象为作者固定类型，
使用正式配置中的个体门槛、B、D、R 参数逐小时计算是否发言。它的用途是跑前预期与故障
诊断，不是实验结果。

| 周 | 预计 Agent 帖数 | 主要形态 |
|---|---:|---|
| W12 | 22 | 事件前低位，营销较多 |
| W13 | 49 | 事件冲击峰，悼念/教育/其他共同抬升 |
| W14 | 34 | 峰后回落 |
| W15–W18 | 16 → 5 | 注意力消耗形成低谷 |
| W19–W20 | 10、10 | 低位试探，玩梗在 W20 出现 |
| W21–W22 | 22、19 | 玩梗成为主要新增供给，但总量远低于 W13 |

这张代理图预期比旧周级 chronological 更“尖锐”：最新 10 条会使同一小时的意见气候高度
一致，短时局部内容簇可能快速自强化；同步批次又限制了同小时的即时连锁，所以脉冲发生在
跨小时而非 Agent 执行顺序内。代理反而给出一个很有信息量、不能预先掩盖的竞争性结果：
W21/W22 玩梗绝对产出为 19/16 条，但因其他类型总量退潮，Agent 供给份额达到约 86%/84%，
未必弱于 interest。也就是说，纯新近性可能通过“最新10条的短时内容簇”形成比个性化兴趣
更强的共同气候。最值得正式 run 检验的是：W13 是否出现清晰峰值、W15–W18 是否形成
深谷，以及 W20–W22 的高玩梗份额究竟来自玩梗绝对量抬升，还是主要来自其他类型退出
造成的分母收缩。若后者成立，应表述为 chronological 产生了集中化，而不能直接写成
interest 对玩梗的选择性激活最强。
