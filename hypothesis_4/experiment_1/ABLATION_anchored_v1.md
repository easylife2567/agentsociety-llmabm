# anchored_v1 三项机制消融预登记

**日期**：2026-09-14  
**状态**：配置已生成，尚未启动消融实验  
**事实基线**：`anchored_v1_interest_s0`  
**完整模型**：

\[
U_{it}=B_i+R_{it}(D_{it}-B_i),\qquad U_{it}\ge a_i \Rightarrow 发言
\]

本轮不再沿用旧公式 \(U=D\cdot R\) 下的 D/R 2×2 设计。新版模型有三个可辨识的
组成部分：常态锚点 \(B_i\)、来源于沉默螺旋的意见气候映射 \(D_{it}\)，以及注意力
余量 \(R_{it}\)。因此在完整模型之外增加三个单因素消融，各只跑 seed 0；完整模型
无需重复跑，总计新增 3 个 run。

## 1. 三个消融条件

| 条件 | 实现操作 | 消融后的公式 | 识别问题 |
|---|---|---|---|
| 完整模型 | B、D、R 全开 | \(U=B+R(D-B)\) | interest s0 已提供 |
| 去 B | `baseline_utility=0` | \(U=RD\) | 常态锚点是否防止注意力耗尽后表达机械归零？ |
| 去 D | `spiral_scale=0`，故 \(D\equiv1\) | \(U=B+R(1-B)\) | 意见气候反馈是否是事件表达被激活的必要条件？ |
| 去 R | `decay=0`，故 \(R\equiv1\) | \(U=D\) | 注意力余量下降是否负责事件冲击退潮与回归常态？ |

两个边界必须特别强调：D 的中性值是 1，所以“去 D”不能把 D 设为 0，而应令
`spiral_scale=0`；R 表示注意力余量，所以“去 R 衰减机制”是令衰减率
\(\lambda=0\)、从而 \(R\equiv1\)，不是令 R=0。

## 3. 预登记比较

每个消融 run 与完整模型逐周比较：五类 Agent 发言率、Agent 供给绝对量与份额、曝光
份额、总供给，以及 W13 事件峰、W15–W19 退潮、W20–W22 玩梗再激活的相位和幅度。

- 去 B 若在后期出现全场供给塌缩，说明 B 承担“回到事件前常态”而非新增事件动力；
- 去 D 若 W20–W22 玩梗再激活明显减弱，支持意见气候反馈是激活机制；
- 去 R 若退潮变浅、各类供给长期维持高位，支持 R 负责消解事件冲击；
- 若某项消融几乎不改变这些结果，则该组成部分在当前操作化下缺乏必要性，应如实报告。

本设计是三项 one-at-a-time 机制消融，不估计三因素高阶交互。若正式结果显示强烈非加性，
再另行预登记全因子扩展；当前不追加 run。
