# D/R/B 正式 replay 离线消融

本目录使用正式实验 `anchored_v1_interest_s0` 的 100 个 Agent × 11 周 decision log，
固定每个 Agent 当周实际落盘的 B、D、R 与表达阈值，离线重算三个单因素消融。没有重新
调用 LLM，也没有重新推进 feed 或环境。

## 公式

| 条件 | 离线门控公式 |
|---|---|
| 完整模型 | `U = B + R(D-B)` |
| 去 B | `U = RD` |
| 去 D | `U = B + R(1-B)`，即 `D≡1` |
| 去 R | `U = D`，即 `R≡1` |

完整模型的 1100 个重算门控与正式 decision log **全部一致**；最大效用重构误差为
`1.0419e-4`（来自日志四位小数舍入）。事实路径存在 1 次“判定发言但未成功生成帖子”
（W16 教育类），反事实无法观测新的 LLM 生成失败，因此所有面板统一使用**门控隐含供给**：
一次反事实发言按一帖计，再加上保持不变的事实注入供给。

## 图形结果

- 去 B：W13 总供给从完整模型的 77 降至 62，W22 从 45 降至 26；常态锚点主要维持
  非事件冲击部分的表达供给。
- 去 D：W12 即出现 12 条玩梗门控供给，完整模型为 0；意见气候不再压制少数类型后，
  玩梗不再呈现“前期潜伏、后期再激活”的相位结构。
- 去 R：W14–W22 总供给长期保持 62–82，完整模型同期为 25–64；悼念、教育、营销和
  其他表达的退潮明显消失。

这些方向只描述**固定事实路径的门控反事实**。消融后的发言不会回写下一周 feed，D/R
也不会重新演化，因此不能将本图写成完成了动态反馈重演的正式消融 run。
