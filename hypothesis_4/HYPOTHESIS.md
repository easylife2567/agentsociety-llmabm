# Hypothesis

## Description

> **当前机制修订（2026-09-14，覆盖下文历史版本中的 `U=D·R` 表述）**：仍只保留沉默螺旋 D 与注意力衰减 R 两条行为机制，不新增第三机制；两者改按锚定式效用组合：`U = B_i + R·(D−B_i)`，当 `U ≥ activity_i` 时发言。`B_i` 是由 W05–W12 事件前常态供给固定的类型效用锚点，`R` 只衰减 `D` 相对常态的事件冲击，因此长期回归常态而不是机械归零。`alpha_D=0.429695` 与五类 `λ_i` 只用 W13–W18 在统一目标函数下标定，W19–W22 严格留出；环境观测量 `B_t/S_t/G_t` 与此处的 `B_i` 含义不同，仍不进入决策。实验结构保持推荐算法单因子三臂 × 3 seeds，不因本次公式修订增加实验因子。

算法策展主假设（2026-09-08 按《实验设计阶段.md》定稿与用户四项裁定重写；2026-09-10 曾把第二因子改为玩梗涌现环境，该因子已于 2026-09-12 随 G 退役，见段末）：推荐算法的个性化兴趣匹配（Agent 类型词表 × 帖子内容特征 + 历史曝光/互动，**不含帖子级热度信号**）会选择性激活既有的玩梗表达群体——同一初始内容池与同一群体构成条件下，兴趣推荐环境中玩梗群体的表达活跃度及其内容的供给/曝光份额显著高于去个性化环境（随机推荐与时序推荐），舆论场对逝者的公共表征构成沿"专业→悼念→迷因"轨迹转移，且转移幅度显著大于两个基线臂。机制定位：玩梗群体事件前已存在于平台生态（真实数据：W05–W12 梗文化内容每周 0–6 条持续产出；用户口径主导类型占比 37.9%，为人数最多的潜伏表达群体），算法改变的是**既有群体的差异化激活与可见度分配**（构成效应），不以个体认知偏移或类型转换为中介——Agent 类型全程固定，仅公开表达/沉默与内容可见性可变。**2026-09-12 用户裁定（机制瘦身）**：原第三因子**玩梗涌现环境增益 G** 退役——no-G 反事实探针实测（run interest_nog_s0）显示玩梗第二波主体不依赖 G（W20-22：38 vs 47 帖 = 0.81），且 G 的两处标定常数与内生存量尺度不匹配（丰沛度 B 自 W13 起饱和为常数 ≈3.6），其净效果是把玩梗型的有效门槛打 3 折并随周漂移，与"类型间不设门槛差异"冲突（见 experiment_1/SMOKE_DIAGNOSIS_w19_cliff.md §五之二/§五之三/§五之四）。故 Agent 只由**沉默螺旋 D + 注意力衰减 R** 两条规则约束（U = D·R ≥ activity），实验组由 3×2 全因子降为**单因子 3 臂**；B/S/G 仍逐周记录于 replay 与监控，作为描述性时间轴与审计线索，不进入任何决策。备择情形分支：(a) 兴趣臂相对基线的差异化激活成立但公共表征未转移 → 激活仅是曝光分配层面现象，需检验供给端与涌现机制；(b) 各臂均转移且臂间无显著差异 → 表征改变由群体内生动力（注意力衰减 + 沉默螺旋）驱动，算法非核心机制，命题修正为"算法×群体内生动力合谋"；(c) 任何臂均不涌现转移 → 微观规则集不足，按模式导向建模原则返回调整初始规则，而非强行修改结果。生成性验证前提：interest 臂须先复现真实"教育→悼念→玩梗"三阶段周级形态（拟合 benchmark_curves.json：W13 悼念份额峰 41.4%±8pp、玩梗 W19 7.8% → W22 60.3% 二波结构定性必需、相位 ±1 周、形状比 log 空间 ±0.3），否则返回调整规则而非下因果结论。因变量：五类表征的内容供给占比与曝光占比周级轨迹（结果层）；各类型 Agent 发言率，及"群体规模→发言比例→供给比例→曝光比例"漏斗的逐级偏移（机制层）。不观测个体认知偏移。分组变量：推荐算法（random / chronological / interest）单因子 3 臂。规模预算（用户 2026-09-08 裁定 100 agents × 11 ticks × 3 seeds；2026-09-12 裁定降为单因子后 = **9 runs ≈0.99 万 agent-ticks**；2026-09-10 裁定群体比例按**发帖人口径**；**2026-09-13 用户更正为营销 23 / 悼念 22 / 其他 21 / 玩梗 19 / 教育 15**）。

## Rationale

理论框架第三层（算法策展/算法放大）将推荐系统定位为信息环境组织者。本版假设按用户裁定将策展操作化为**纯兴趣匹配**（无热度项）：这是个性化策展的最小机制——若仅凭"类型词表匹配 + 历史行为"的选择性曝光即可差异化激活既有玩梗群体并驱动公共表征转移，则个性化策展本身构成充分放大机制；若不能涌现，则为"热度/互动信号是放大必要成分"提供反证，机制归因边界同样具有理论价值。与"认知偏移"框架的区别不变：机制是群体层面的构成效应——个体无需转变，表征构成改变来自哪类既有群体被激活、被看见。数据实证三重支撑：①真实曲线"教育→悼念→玩梗"三阶段转移（W13 悼念 41.4% 峰值，W19–W22 玩梗 7.8%→60.3%，benchmark_curves.json）；②平台分化（抖音玩梗 W22 82% vs 小红书 19%）表明策展逻辑差异决定放大速率；③用户口径 vs 内容口径的结构性错位（梗文化：37.9% 用户 vs 13.6% 内容；营销：12.6% 用户 vs 30.7% 内容）表明玩梗群体是人数最多、常态表达最低的潜伏群体，差异化激活空间最大，故 Agent 比例按用户（发帖人）口径设定。**机制瘦身（2026-09-12 用户裁定）**：第三因子"玩梗涌现环境增益 G"退役，Agent 只由**沉默螺旋 D**（同类气候共振放大表达收益、少数派处境抑制收益）与**注意力衰减 R**（重复同类曝光折减收益，半饱和尺度 **15** ≈ 一周半活跃曝光；2026-09-12 由 50 调至 20、2026-09-13 进一步下压至 15，以显现事件后的疲劳退潮）两条规则约束，`U = D·R ≥ activity`。D 改用**有界 tanh**：`D = 1 + s·tanh(1.5·(share_own − base)/base)`（实现在共享纯函数 curation_mechanisms.spiral_factor，agent 与校准脚本同源）。形式化依据：Blanco (2005) 的博弈模型给出"发言门槛 = 孤立成本/(收益+成本)"，与本模型的门槛结构同构（D<0 即表达存在净成本=孤立成本）；Sohn & Geidner / Cabrera et al. 用 logistic 有界映射把意见气候 δ 转成表达意愿；Granovetter 阈值分布对应 activity 的 U[0.8,1.2] 个体抖动；测量学规范要求"实际意见 / 感知气候 / 表达意愿"分开测量，本模型 D 读 agent 本人 feed 的构成（感知气候），曝光份额作实际气候（对照）。G 退役的实测依据与文献对照见 experiment_1/SMOKE_DIAGNOSIS_w19_cliff.md §五之四。机制链（沉默螺旋 + 注意力衰减 → 发言决策 U = D·R；类型固定 → 内容类型不变）的微观规则详见《实验设计阶段.md》。配置裁定：2026-09-08 四项（纯兴趣匹配、用户口径群体比例、11 ticks × 3 seeds）+ 2026-09-10（发帖人口径、发言基于所见、feed_size=10）+ 2026-09-13（群体构成更正为 19/22/23/15/21）+ 2026-09-12（G 退役 → 单因子 3 臂 × 3 seeds = 9 runs；D 改有界 tanh）+ 同日 feed 机制重设计（帖子生命周期 + 曝光饱和 + 兴趣比例抽样）。

## Experiment Groups

### Group 1: random

**Type:** control

**Description:** 弱策展基线：随机推荐。Agent 从公共内容池（未退场的活帖，跨臂同源）均匀随机获得帖子，兴趣与历史不影响曝光。

**Agent Selection Criteria:** 全体 100 agents（营销 23 / 悼念 22 / 其他 21 / 玩梗 19 / 教育 15，发帖人口径）; recommendation_algorithm=random

### Group 2: chronological

**Type:** control

**Description:** 去个性化时序基线：时序推荐（发布时间倒序取最新）。

**Agent Selection Criteria:** 全体 100 agents（同上）; recommendation_algorithm=chronological

### Group 3: interest

**Type:** treatment

**Description:** 主治疗臂：兴趣推荐（类型词表×帖子特征匹配的比例抽样，无热度项）。兼任生成性验证 run——须复现真实三阶段形态（拟合 benchmark_curves.json），通过后方可进行臂间因果比较。

**Agent Selection Criteria:** 全体 100 agents（同上）; recommendation_algorithm=interest
