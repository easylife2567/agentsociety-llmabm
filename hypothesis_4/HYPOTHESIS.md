# Hypothesis

## Description

算法策展主假设：推荐算法（热度加权）选择性放大已有的玩梗群体，从而改变公共表征——同一供给池与同一群体构成条件下，玩梗群体（平台生态中常驻的梗文化类群）的曝光与互动份额显著超过其群体供给占比（选择性放大），专业内容群体的份额相对被抑制，舆论场对逝者的公共表征构成随之沿"专业→悼念→迷因"轨迹转移，且转移幅度显著大于去策展化环境（时间线排序）。机制定位：玩梗群体在事件前已存在于平台生态（真实数据：事件前 W05–W12 梗文化类群持续有小量产出），算法改变的是**群体可见度分布**（哪类群体被看见），而非个体认知——公共表征改变由群体构成层面的选择性放大驱动，不以个体认知偏移为中介。备择情形分支：(a) 选择性放大成立但公共表征未转移 → 放大只是表征分配层面的现象而非转移的充分驱动，需检验群体再生产与供给端；(b) 选择性放大不成立但表征仍转移 → 表征改变由群体内生动力（自选择、模仿、再生产）驱动，命题修正为"算法×群体内生动力合谋"；(c) 两者均不成立 → 推荐算法非核心机制，核心命题退回"数字哀悼+模因竞争"解释。生成性验证前提：策展基线 run 须先复现真实三阶段表征转移形态（拟合 benchmark_curves.json），否则返回调整规则而非下因果结论。因变量：玩梗群体及各内容类群的曝光/互动份额相对其供给占比的偏移（机制层，主）；舆论场公共表征类别份额轨迹与转移幅度（结果层）。不观测个体认知偏移。分组变量：推荐机制（热度加权 reddit_hot vs 时间线 chronological）。

## Rationale

理论框架第三层（算法策展/算法放大）将推荐系统定位为信息环境组织者与核心机制变量：高互动内容获得更高曝光，形成"注意力→再生产→更高注意力"的策展回路。本假设将放大对象从"内容"精确定位到"群体"：梗文化群体是平台生态的常驻群体（数据实证：事件前 W05–W12 梗文化类群每周 0–6 条持续产出，事件后就地转向以逝者为素材），社会表征理论（Moscovici）与模因理论预测高情绪、高可复制符号在传播竞争中占优，而热度加权将这种占优制度化为群体可见度的系统性倾斜。与"认知偏移"框架的区别：本假设的机制是群体层面的选择性放大（构成效应）——个体无需转变，表征构成的改变来自哪类群体被算法看见；这对应平台研究中算法放大与可见性分配文献，而非态度改变文献。数据实证：真实曲线显示"教育→悼念→玩梗"三阶段转移（W13 悼念 44% 峰值，W19–W22 玩梗 9%→63%）。单一主假设结构由用户裁定（2026-08-31）；研究焦点从认知偏移转向群体选择性放大由用户裁定（2026-09-08）。对应文献索引中算法策展/平台研究主题。

## Experiment Groups

### Group 1: control_curation_hot

**Type:** control

**Description:** 策展基线：热度加权推荐（reddit_hot），完整算法策展环境；同时兼任生成性验证 run（须先复现真实"专业→悼念→迷因"三阶段周级形态，拟合 benchmark_curves.json）

**Agent Selection Criteria:** 内容类群代表 agents（须含玩梗群体；类群划分与占比由真实打标数据决定，具体实现见实验配置）; recommendation_algorithm=reddit_hot


### Group 2: treatment_decuration_chrono

**Type:** treatment

**Description:** 去策展化：时间线排序（chronological），移除热度加权与策展信号；同供给同 agent 同种子（与基线唯一差异是 recommendation_algorithm）

**Agent Selection Criteria:** 内容类群代表 agents（同基线）; recommendation_algorithm=chronological
