# 主实验启动执行历史

本目录属于[统一timestamp_v1主实验](../README.md)。两次启动的授权、预算和停止/恢复过程分别保全，不代表两项实验；全部30次完整结果在同一上级目录按算法×seed排列。

| 直接资产 | 用途 |
|---|---|
| [seed0_2/](seed0_2/README.md) | 原seed0–2九次启动的控制与预算历史 |
| [seed3_9/](seed3_9/README.md) | 后续seed3–9二十一次启动、联停、恢复、完成及预算历史 |
| code_before_storage_merge/ | 本次5个读取文件修改前的原字节；原路径、校验和及代码基线见上级relocation.json，修改补丁见实验目录 |

原运行记录、账本与冻结证据保持，只有存放位置变化。现有读取器通过实验目录run_asset_paths.py定位历史路径，避免改写原始证据。无运行进程、无新的启动授权；不要将历史预算或状态解释为继续运行许可。
